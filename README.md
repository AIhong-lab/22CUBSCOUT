# 幼童軍進程與技能章查詢系統

家長從 LINE 官方帳號打開網頁，就能看到孩子的入團時間、已拿到與正在挑戰的進程和技能章。團長與服務員從同一個入口進後台，管理名單、簽核項目、登錄頒章；條件達成時，LINE 會主動通知團長。

- 前端：GitHub Pages 上的單一網頁（LINE LIFF）
- 後端：Google Apps Script
- 資料：Google 試算表（只放在團長的 Google 帳號，repo 裡沒有任何孩子的資料或金鑰）
