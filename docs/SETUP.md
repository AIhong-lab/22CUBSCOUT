# 設定步驟（SETUP）

> 依階段逐步補齊；階段 4A 寫到足以上線，階段 6 定稿。
> 每一步標示：📝 = 要抄下來的值，➡️ = 要填到哪裡。抄下的值存在自己的記事本，**不要**貼到 GitHub、群組或截圖。
> 標示「（待補）」的步驟會在之後的階段寫完整。

## 1. Google 試算表與 Apps Script 專案
已在階段 0B 完成（試算表「幼童軍進程系統」與其 Apps Script 專案）。從零架設時：
1. 用**團務 Google 帳號**開 https://sheets.new ，改名「幼童軍進程系統」。
2. 「擴充功能」→「Apps Script」，專案改名「幼童軍進程系統」。

## 2. LINE Developers（官方帳號 Messaging API）
已在階段 0B 完成。從零架設時見 `docs/SETUP-0B.md` 的 E 段。

## 3. Script Properties（指令碼屬性）
Apps Script →「專案設定」（齒輪）→ 最下方「指令碼屬性」。

| 屬性 | 誰填 | 說明 |
|---|---|---|
| `SPREADSHEET_ID` | `setup()` 自動 | 試算表 ID |
| `WEBHOOK_KEY` | `setup()` 自動（0B 已產生則沿用） | LINE webhook 網址的 `?key=` |
| `LINE_MESSAGING_TOKEN` | 團長手動 | LINE Developers → Messaging API → Channel access token |
| `BACKUP_FOLDER_ID` | `setup()` 自動 | 備份資料夾 ID（自動建立「幼童軍進程系統備份」資料夾） |
| `WEB_URL` | 團長手動（選用） | 網頁網址 `https://aihong-lab.github.io/22CUBSCOUT/web/`，LINE 通知的按鈕會用到 |

## 4. 更新後端程式（不需安裝任何工具）
每次我說「後端有更新」時照做：
1. 開 https://github.com/AIhong-lab/22CUBSCOUT/blob/main/dist/Code.gs ，按程式碼框右上角「複製」圖示（Copy raw file）。
2. Apps Script 左側「檔案」點 `程式碼.gs` → `Ctrl + A` 全選 → `Ctrl + V` 貼上（整份取代）→ 按「儲存」。
   - 專案裡只應該有 `程式碼.gs` 這一個 .gs 檔；如果有其他 .gs 檔請告訴我。
3. **執行 setup**：函式選 `setup` →「執行」（新版程式新增的分頁會在這一步建立，例如「進程細項」；已有資料的分頁不會被覆蓋）。如果跳出授權視窗（新版程式可能多了雲端硬碟、排程等權限），照之前的方式允許。沒有跳出就表示不需要。
4. 右上「部署」→「管理部署作業」→ 鉛筆圖示 → 版本選「**新版本**」→「部署」。**網址不變**，LINE 與網頁都不用改。
   - ⚠️ 只貼程式、沒有部署新版本的話，網站用的還是舊程式（會出現「不支援的操作」）。

> 進階：也可以用 clasp（`cd gas && clasp push`），兩種方式擇一，不要混用。

## 5. GitHub Pages
已在階段 0B 完成（Settings → Pages → main / root）。正式網頁網址（階段 3 起）：`https://aihong-lab.github.io/22CUBSCOUT/web/`

## 6. webhook 網址、關閉官方帳號內建自動回應
已在階段 0B 完成。網址格式：`GAS 網址?key=WEBHOOK_KEY 的值`。

## 7. 備份資料夾與每週備份（自動）
不用手動設定：第 8 步執行 `setup()` 時，會自動在你的雲端硬碟建立「幼童軍進程系統備份」資料夾（只有你看得到），並開啟每週日凌晨 3 點自動備份。執行紀錄會出現「建立備份資料夾」「開啟每週日 03:00 自動備份」。之後在網頁後台「💾 備份與權限」看上次備份時間、按「立即備份」。

## 8. 執行 setup()
1. Apps Script 上方函式選單選 `setup` →「執行」。第一次會要求授權，同 0B（進階 → 前往 → 允許）。
2. 看下方「執行記錄」：
   - 「新建立分頁：……」：應列出 25 個分頁（已存在的不會重建）。
   - 「匯入資料：項目總表 163 列、級別與章說明 30 列、告知同意內容 第 1 版、設定 補上 20 項」。
   - 「第一位團長邀請碼：XXXXXXXX（有效到 ……）」📝 抄下這組碼（**不要截圖給任何人**），階段 3 網頁完成後用它註冊你的團長帳號。72 小時內有效；過期就再執行一次 `setup()`，會產生新的一組。
3. 回試算表檢查：「顯示全部分頁」後應有 25 個分頁；「項目總表」有 163 列官方原文項目；「設定」有 20 項。
4. `setup()` 可以重複執行，**不會覆蓋**任何已有資料。
5. 若 0B 測試帳號還沒清：函式選 `cleanup0B` →「執行」。

> 排程（每日通知、每週備份）的安裝在階段 4A／5 補上。

## 9. 把自己設成第一位團長
用第 8 步的邀請碼，在網頁「登入 → 我有綁定碼」輸入（小孩姓名留空），設定帳號密碼即成為團長。

### 建立你自己的團長帳號（最高權限）
**最快**：打開試算表（重新整理一次）→ 上方選單「🐺 幼童軍系統 → 🔑 團長預設帳號（admin）」→ 視窗會顯示帳號 `admin` 和一組隨機密碼，抄下來登入網站，再到「我的 → 修改密碼」改成自己的。忘記密碼時再按一次會重設。

或者用自己的帳號：
1. 網站 →「登入」→「註冊新帳號」→ 選「服務員」→ 填姓名、帳號（例如 `leader_hong`）、密碼 → 送出。
2. 打開試算表（重新整理一次）→ 上方選單「🐺 幼童軍系統 → **把帳號設為團長**」→ 輸入剛才的帳號 → 確定。
3. 回網站重新登入，就會進入後台，擁有全部權限。
（第一次架設時也可以用 setup 印出的「第一位團長邀請碼」，在「我有綁定碼」輸入。）

### 加入其他服務員／團長
請對方自己到網站「登入 → 註冊新帳號」選「服務員」，你在後台「📝 帳號申請」核准。要改成團長：後台「更多 → 👥 管理員」→ 管理 → 角色改團長。（邀請碼功能已拿掉。）

## 10. 試算表與備份資料夾的分享權限
1. 試算表右上「共用」：一般存取權設為「**限制**」（不可是「知道連結的任何人」）；使用者只留團長本人（必要時加一位副團長）。服務員**不需要**試算表權限，他們用網頁後台。
2. 備份資料夾：右鍵 →「共用」→ 同樣設為「限制」。
3. 網頁後台「更多 → 備份與權限」→「檢查試算表權限」，應顯示「✅ 權限正常」。每週備份時也會自動檢查一次，有問題會在後台首頁顯示紅色警告。
## 11. 確認個資告知同意內容
試算表「告知同意內容」第 1 版的【請填寫：……】要在家長註冊前改成實際內容（尚無人同意前直接修改即可，不需加版本）。內容說明見 `docs/PRIVACY.md`。
## 12. LINE 圖文選單（給所有人看的六個按鈕）
六個按鈕都是「開網頁」，內容都在 22 團的網站裡，之後改內容不用再動 LINE。
1. 下載選單圖片：https://github.com/AIhong-lab/22CUBSCOUT/blob/main/docs/line-richmenu.jpg （按右上角的下載圖示）。
2. 到 LINE Official Account Manager（manager.line.biz）→ 選官方帳號 →「主頁 → 圖文選單」→「建立」。
3. 標題自訂（例如「22團選單」），使用期間設長一點（例如 5 年）。
4. 「選擇版型」選**大型、六格（三欄兩列）**的那一個；「建立圖片 → 上傳背景圖片」選剛才下載的圖。
5. 六格的「類型」都選「**連結**」，依序填入（A～C 是上排左到右，D～F 是下排左到右）：

| 格 | 按鈕 | 網址 |
|---|---|---|
| A | 公佈欄 | `https://aihong-lab.github.io/22CUBSCOUT/web/#notices` |
| B | 進程查詢 | `https://aihong-lab.github.io/22CUBSCOUT/web/#progress` |
| C | 技能章查詢 | `https://aihong-lab.github.io/22CUBSCOUT/web/#badges` |
| D | 了解幼童軍 | `https://aihong-lab.github.io/22CUBSCOUT/web/#about` |
| E | 活動時間 | `https://aihong-lab.github.io/22CUBSCOUT/web/#calendar` |
| F | 22團 FB | 你們的 Facebook 粉絲專頁網址 |

   每一格的「動作標籤」填按鈕名稱即可。
6. 「選單列顯示文字」可填「選單」，「預設顯示方式」選「顯示」，按「儲存」。
7. 到網站後台「系統設定 → 🌐 網站內容」填好「了解幼童軍」「活動時間說明」「FB 網址」。
8. 用手機打開官方帳號聊天室，六個按鈕各按一次確認。

管理員的關鍵字「可晉級」「快達標」還是可以直接在聊天室打字使用（只有已連結 LINE 的管理員會收到名單）。
⚠️ 這一節沒有在真實 LINE 後台驗證過，選單名稱可能和實際畫面略有不同。
## 13. 上線流程（網頁後台操作）
1. **連結 LINE 通知**：後台「更多 → 連結 LINE 通知」→ 取得 6 位數配對碼 → 在官方帳號聊天室輸入。（通知功能在階段 5 啟用，先連好。）
2. **指定其他管理員**：「更多 → 帳號與權限」→ 已有帳號的人用「從已註冊的帳號指定」；沒有帳號的請對方自己註冊選「服務員」，再到「帳號申請」核准。
3. **設定小隊**：「更多 → 🏕️ 小隊設定」，依序新增你們團的小隊（可以改名、調整順序）。
4. **輸入名單與入團日**：「小狼 → ＋ 新增小狼」，小隊用選的；每新增一位就自動產生綁定碼。
5. **補登既有頒章**：點進每位小狼 →「📥 補登頒章」，選級別或技能章與頒發日期。較低級別沒有紀錄時會詢問是否一併補登。補登不會發通知。
6. **填技能章說明**（選做）：試算表「級別與章說明」的「說明」欄。說明留空時網頁不顯示空白區塊。
7. **輸入集會行事曆**：「更多 → 行事曆」，一次貼上整學期（每行一場：`2026-11-22 團集會`）。
8. **設定年度出席**：「更多 → 年度出席」，填年度起訖與應出席總數。
9. **確認個資說明**（第 11 步）後，**發綁定碼給家長**：點進小狼 →「📋 複製給家長的說明文字」→ 用 LINE 傳給家長。
10. 測試帳號（例如 C-TEST1、test 開頭的帳號）上線前用「更多 → 個資處理 → 完全刪除」與「帳號管理 → 刪除帳號」清掉。
