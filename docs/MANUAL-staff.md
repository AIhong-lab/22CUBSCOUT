# 22團網站　服務員版操作手冊

> 網址：**https://aihong-lab.github.io/22CUBSCOUT/**（建議「加入主畫面」變成手機上的 App，方法見下方）
> 有任何問題請聯絡團長。完整版手冊：`docs/MANUAL.md`

## 把網站變成手機上的 App（加入主畫面）
不用到 App Store 下載，網站本身就可以裝到手機桌面，點開是全螢幕、沒有網址列：
- **iPhone**：用 **Safari** 打開網站 → 下方「分享」按鈕 →「加入主畫面」→「新增」。
- **Android**：用 **Chrome** 打開網站 → 右上角「⋮」→「安裝應用程式」（或「加到主畫面」）。
- 從 LINE 點開的網頁不能直接安裝：先按右上角「⋯」→「用預設瀏覽器開啟」，再照上面做。
- iPhone 第一次從桌面圖示打開時要**再登入一次**（桌面 App 和 Safari 的登入是分開的），之後就會記住。
- 網站更新時桌面 App 會自動跟著更新，不用重新安裝。沒有網路時 App 打得開，但資料要有網路才看得到。

## 使用方式

### 1. 加入
1. 打開網站 → 右上角「🔑 登入」→「**註冊新帳號**」→ 選身分「**服務員**」。
2. 填你的**姓名**（會顯示在管理員名單）、選**要加入的分團**、**帳號**、**密碼**。自己的孩子也在團裡的話，勾「我也有孩子在團裡」並填孩子姓名（會多一步個資說明）。
3. 送出後顯示「等待團長審核」。團長核准後重新登入，就會直接進後台。

（已經用家長身分註冊過的人，不用重新註冊，請團長幫你把帳號調整成服務員。）

（拿到團長給的**邀請碼**時：「註冊新帳號 → 我有綁定碼」輸入邀請碼，註冊完就直接是該分團的服務員，不用等審核。）

> **各分團內容隔離與動態權限**：後台與前台皆只會顯示**你所屬分團**（與全團開放）的團員、點名、公告、活動，不會看到其他分團的內部資料。實際顯示的功能分頁由**總團／管理員**於「權限設定」統一控管；兼任多個分團者，後台右上角有「分團切換」選單。五個分團都有進程與章（簽核、頒章、總覽、列印）：童軍與行義共用初級到國花六級與 95 個專科章，羅浮是見習、授銜、服務三個階段（沒有專科章）。

> 🔒 **改密碼、改稱呼與 LINE 通知**：統一在後台「👤 我的帳號與 LINE」操作。

> **選單名稱對照（2026-11-15 整理）**：「帳號申請」＝原本的註冊審核；「總覽」裡切換進程／出席；「行事曆」裡切換集會行事曆／年度出席；「帳號與權限」裡切換管理員／所有帳號（原本的帳號管理）；「列印紙本」＝原本的列印簽核單。功能都沒有變，只是合併與改名。

### 2. 精簡版後台首頁與選單
後台首頁已精簡為**直接顯示「🛠️ 今天要做的事」**（今日集會、快速點名／簽核入口、待辦與系統提示）；需要看前台公開頁面時，點選「📖 查看公開網站」即可。

服務員常用功能已整合為清晰的主選單（依總團「權限設定」動態顯示可用分頁）：

| 選單入口 | 服務員可用功能 |
|---|---|
| 🏠 **首頁** | 今日集會（直達點名／簽核）、待頒章與快達標名單 |
| 📋 **集會與點名** | 團集會點名 |
| ✅ **進程與頒章** | 進程簽核、進程總覽、列印簽核單（目前開放幼童軍） |
| 👥 **團員與幹部** | 團員名單、出席總覽 |
| 📣 **公告與活動** | 發布與管理本分團公佈欄 |
| 👤 **我的帳號與 LINE** | 修改稱呼／密碼、連結或解除 LINE 通知 |

### 3. 點名（團集會現場）
1. 「📋 點名」→ 會自動選好**今天的集會**（今天沒有就選最近一場，上方可以換）。
2. 上方選**小隊**（或全團）。
3. 按「**✅ 全部出席**」→ 再把**遲到、請假的**改掉（點一下切換：空白 → 🐾 出席 → ⏰ 遲到 → 🌙 請假 → 空白）。遲到也算出席，只是多一個標記。
4. 按「**儲存點名**」。

> - 沒來也沒請假的，保持空白即可（系統不記錄缺席）。
> - 還沒儲存就離開會跳出提醒。
> - 兩位服務員可以同時點不同小隊，不會互相覆蓋。
> - 羚羊級「參加幼童軍團集會至少 4 次」會在出席滿 4 次時**自動打勾**，不用另外簽。

> 🧪 **體驗者**（還沒入團的小朋友）只出現在一般團集會的點名，名字旁邊有「🧪 體驗」；大活動不列體驗者。照常點出席或請假就好。

### 4. 簽核（小隊一起簽，最常用）
簽核分成三步，畫面下方的按鈕一步一步往下：
1. **① 選小隊** →「下一步：選項目」。
2. **② 選項目**：上方選單選級別或技能章（「⭐ 最近簽過的項目」在最前面），大項多時可以再點大項篩選，勾選這次完成的項目。每個項目下面會顯示「已完成 x／y 位」。
   - **可以跨級簽**：照團集會實際做的內容簽，不用管小狼現在幾級。例如羚羊級的小狼做了椅子，就選「進程・豹級」→ 勞作，簽鐵鎚、鋸子那一項。
3. **③ 選小狼與日期**：預設全選該小隊，沒完成的取消勾選；日期預設今天，可改成過去的日期 →「**送出簽核**」。
4. 送出後會回到第 ② 步，可以接著簽下一批；簽錯了馬上按「**↩️ 復原剛才這一批**」。

### 5. 單人簽核、撤銷
「👥 團員」→ 點團員 → 上方切換「進程／技能章／家長帳號」→ 展開級別或技能章（編輯、補登、列印、離團、個資處理收在右邊的「⋯」）：
- 勾選未完成的項目 → 選日期 →「簽核勾選的項目」。
- 已完成的項目旁有「撤銷」：服務員**只能撤銷自己簽的**。

### 6. 列印簽核單
「✅ 進程與頒章」→ 上方切換「🖨️ 列印」→ 選級別 → 選小隊或小狼 →「列印」（A4，每位小狼一頁）。

### 7. LINE 官方帳號（連結通知、關鍵字、選單）
**連結（一次就好）**：網站後台「👤 我的帳號與 LINE」→ 取得 6 位數配對碼（10 分鐘內有效）→ 手機 LINE 加入 22 團官方帳號 → 在聊天室輸入這 6 位數 → 收到「已連結」就完成。換手機或換 LINE 帳號時再做一次。

**連結後會收到**：有小狼達標（可以頒章）時，官方帳號會傳一則通知給所有已連結的團長與服務員；按「前往頒章」會打開網站（頒章只有團長能做）。超過 14 天還沒頒會再提醒一次。

**在聊天室輸入關鍵字**（只有已連結的團長與服務員會收到名單；回覆不會用掉推播額度）：

| 輸入 | 回覆 |
|---|---|
| 點名 | 今天（沒有就下一場）的集會、已請假的孩子名單，和直達那一場點名畫面的連結 |
| 可晉級 | 已達標、還沒頒章的名單 |
| 快達標 | 再完成幾項就達標的名單 |
| 進度 | 網站連結（任何人都可以用） |

**聊天室下方的六個按鈕**（任何人都看得到）：

| 位置 | 按鈕 | 打開什麼 | 要登入嗎 |
|---|---|---|---|
| 上排左 | 📣 公佈欄 | 最新公告、團集會通知 | 不用 |
| 上排中 | 🗺️ 進程查詢 | 剛入團、羚羊、狼、鹿、豹每一級要做什麼 | 不用 |
| 上排右 | 🎖️ 章查詢 | 各分團的章（幼童軍：26 個技能章的合格標準） | 不用 |
| 下排左 | 🧭 認識 22 團 | 團的介紹、五個分團、怎麼加入、聯絡方式 | 不用 |
| 下排中 | 📅 活動時間 | 團集會月曆、活動報名的起訖日 | 不用 |
| 下排右 | 👍 22團 FB | 22 團的 Facebook 粉絲專頁 | 不用 |

**小技巧**：團集會現場在聊天室打「點名」，先看誰請假，再點回覆裡的連結直接開始點名。

### 8. 公佈欄
後台「📣 公告與活動」→「📣 公佈欄」（手機在「☰ 更多」裡）→ 填標題、內容，可以選「連到哪一場集會」和「置頂」→ 發布。
- 公告**不用登入就看得到**，會出現在網站首頁，所以**不要寫孩子的姓名或其他個人資料**。
- 寫錯了按「修改」；不需要了按「下架」（之後可以重新上架）。

### 9. 我是小隊輔
團長把你設成某個小隊的小隊輔之後，你進「點名」「簽核」時會預設選到你的小隊（還是可以切換到其他小隊或全團）。家長會看到孩子的小隊輔姓名。點名畫面上已經標「請假」的，可能是家長自己在網站上先請的假。

### 10. 活動報名
服務員自己要參加活動，也是到網站首頁「🎪 活動報名」填表（身分別選「服務員」）。額滿後送出的會排候補，由團長轉為正取。建立活動、看全部名單和登記繳費是團長的工作。

## 服務員可以做與不能做的事
- ✅ 可以：點名、簽核、撤銷**自己簽的**項目、看小狼名單與總覽、列印簽核單、連結 LINE 通知。
- ❌ 團長才能做：帳號申請、頒章與補登、新增或編輯小狼、綁定碼、行事曆與年度出席、管理員與帳號、個資處理、備份。

## 常見問題

**Q：網頁看起來是舊的？**
A：按 `Ctrl + Shift + R`（電腦）或關掉分頁重新打開（手機）。

**Q：畫面顯示「登入已過期」？**
A：重新登入即可，登入後會回到剛才的畫面。

**Q：簽錯了怎麼辦？**
A：剛送出的整批按「復原」；單一項目到小狼頁按「撤銷」。

**Q：服務員看不到某些功能或分頁？**
A：各分頁與功能由**總團／管理員**在「權限設定」中統一控制（且各分團內容彼此隔離）。若某項功能僅開放給正副團長、或在你的分團被停用，系統會自動隱藏；如有業務需要，請聯絡分團團長或總團調整權限。

**Q：在 LINE 輸入「點名」沒有回應？**
A：要先完成「連結 LINE 通知」（第 7 節）。已經連結還是沒反應，請告訴團長。

## 稚齡童軍的服務員（2026-11 起）
- 後台的簽核、團員頁、進程總覽、列印簽核單和小狼一樣用法，只是級別是**地球 → 星星 → 月亮 → 太陽**，技能章分服務類、運動類、技巧類。
- 星星、月亮、太陽的第一項「獲得上一級章後至少參加 N 次團集會」，請看孩子的出席紀錄**自己勾選簽核**（系統不會自動打勾）。
- 團員頁和後台首頁會提醒**完成期限**（例如地球要在入團後 6 個月內完成）；這只是提醒，過了期限一樣可以頒章。家長看不到這個期限。

## 童軍、行義、羅浮的服務員（2026-11-27 起）
- **童軍、行義共用一套進程**：初級 → 中級 → 高級 → 獅級 → 長城 → 國花；章叫「專科章」。行義的孩子從高級接著往上，之前在童軍完成的都會保留。
- 獅級、長城、國花的「取得專科章 N 種以上…」那一項，請在孩子真的拿到縣（市）童軍會頒發的專科章後再簽核。
- **羅浮**：見習羅浮的「途徑1」「途徑2」選一條完成就好；服務羅浮的「主題活動」任選一項。
- 晉級間隔（例如中級要初級頒發後滿 4 個月）未滿時，後台會顯示「等條件」，不影響簽核。
- 孩子從別的分團升上來時，團員頁有「📜 之前分團的紀錄」可以看他以前拿過的章。
