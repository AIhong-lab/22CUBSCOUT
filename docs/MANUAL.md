## 〇、把網站變成手機上的 App（加入主畫面）
不用到 App Store 下載，網站本身就可以裝到手機桌面，點開是全螢幕、沒有網址列：
- **iPhone**：用 **Safari** 打開網站 → 下方「分享」按鈕 →「加入主畫面」→「新增」。
- **Android**：用 **Chrome** 打開網站 → 右上角「⋮」→「安裝應用程式」（或「加到主畫面」）。
- 從 LINE 點開的網頁不能直接安裝：先按右上角「⋯」→「用預設瀏覽器開啟」，再照上面做。
- iPhone 第一次從桌面圖示打開時要**再登入一次**（桌面 App 和 Safari 的登入是分開的），之後就會記住。
- 網站更新時桌面 App 會自動跟著更新，不用重新安裝。沒有網路時 App 打得開，但資料要有網路才看得到。

## 二、家長篇

### 1. 第一次使用：註冊（約 2 分鐘）
需要準備：**孩子的全名**。

1. 打開網站 → 右上角「🔑 登入」→「**註冊新帳號**」。
2. 選身分「**家長**」。（同時是家長和服務員的話選「服務員」，或先選家長，之後請團長幫你調整。）
3. 填**孩子的姓名**（有兩個以上孩子在團裡，按「＋ 再加一位孩子」）、你的**稱呼**（例如「王小明媽媽」）、**帳號**（4～20 個英文字母、數字或底線，例如 `xiaoming_mom`）、**密碼**（至少 8 個字）。
4. 閱讀**個資說明** → 勾選同意 →「同意並送出申請」。
5. 畫面會顯示「**等待團長審核**」。團長核准後，再登入（或按「重新整理」）就能看到孩子的冒險紀錄。

> 爸爸、媽媽可以各自註冊同一個孩子，團長審核時會把你們連到同一位小狼。
> 按「不同意」不會建立帳號，也不會留下任何資料。
> 如果團長給了你「綁定碼」，也可以用登入頁的「我有綁定碼」註冊，不需要等審核。

### 2. 之後登入
帳號＋密碼 → 勾「記住我」，這台手機下次就不用再登入。

### 3. 看孩子的進度（3 個分頁；手機在螢幕下方、電腦在上方）
| 分頁 | 看什麼 |
|---|---|
| 🏠 **首頁** | 孩子的基本資料、這一級的進度、技能章數、出席率；**下一步挑戰**（接下來要完成的任務）；下次集會；正在挑戰的、已經拿到的章 |
| 🗺️ **進度** | 上方可以切換三種：**闖關**（剛入團→羚羊→狼→鹿→豹，點關卡看每一項任務、完成日期、晉級條件、📋 本團細項，可列印簽核單）、**徽章**（技能章收藏冊，點徽章看合格標準）、**出席**（出席率、每次集會的紀錄） |
| 👤 **我的** | 帳號、修改稱呼與密碼、綁定的孩子、新增孩子、解除綁定、個資說明、登出 |

**體驗者**：還沒入團的孩子，首頁會顯示「一般團集會 x／4 次」。參加滿 4 次一般團集會（大活動不算）後，由團長轉為入團，之後開始挑戰「🌱 剛入團」。

**狀態說明**
- 🔒 未開始／🔥 挑戰中：還有任務沒完成。
- ⏳ 等待頒發：任務都完成了，「項目已全部完成，等待團長評核頒發」。
- 🏅 已拿到：團長已頒發，會顯示頒發日期。

> 孩子完成任務後，要在團集會時請團長或服務員**簽核**，網站上的星星才會亮起來。
> 進程是依團集會實際完成的內容簽核，所以孩子有時會先完成比目前級別更高的任務（例如羚羊級先做了豹級的木工），那一級會先顯示「🔥 挑戰中」，這是正常的。
> 家長在紙本簽名的項目，由團長登記到系統後才會亮起來。

### 3-1. 公告、接下來的集會與請假
- 導覽列上有「📣 公佈欄」分頁（手機在螢幕下方），不用登入也看得到。
- **公佈欄**：團裡的公告會出現在網站首頁（不用登入也看得到）和你登入後的首頁。
- **接下來的集會**：「🗺️ 進度 → 🐾 出席」會列出接下來的集會（日期、名稱、備註）。
- **線上請假**：不能來的那一場按「請假」，點名時服務員就會看到；計畫改變可以按「取消」。已經過了的集會、或已經點名為出席的，請直接聯絡團長或服務員。請假不算出席。
- 首頁也會顯示孩子的小隊輔是誰，以及孩子是不是小隊長、副小隊長。

### 4. 有第二個孩子與分團內容隔離
- 「👤 我的」→「＋ 新增孩子」→ 填孩子姓名並選分團 → 勾選同意 →「送出申請」。團長核准後，畫面上方可以切換孩子；切換時標題會顯示孩子的分團。
- **分團內容隔離**：家長登入後，只會看到自己綁定的孩子、所屬分團與「全團」的公告、月曆與活動；前台首頁也會自動隱藏其他分團卡片。實際看得到的分頁（如公佈欄、進度、請假、活動報名）均由總團於「權限設定」統一控管。

### 4-1. 童軍以上（有手機）建立「本人帳號」
「童軍、行義、羅浮」的團員若有自己的手機，家長可在「👤 我的 → 📱 為童軍以上孩子建立本人帳號」直接替孩子建立獨立帳號：
- 該帳號會以「本人」關係單獨綁定這一位團員，**僅能看到自己的帳號與進度／出席紀錄**，無法再綁定其他團員或查看他分團資料。
- 線上請假與活動報名預設僅開放「家長」操作（總團可視需要於「權限設定」調整是否開放給「童軍本人」）。

### 5. 忘記密碼或帳號
請**聯絡團長**。團長會用 LINE 傳一組「**臨時碼**」給你：
登入頁 →「忘記密碼？」→ 輸入帳號、臨時碼、新密碼。臨時碼只能用一次，有使用期限。

### 6. 個資說明更新時
團長更新個資說明後，下次登入會請你重新閱讀並同意。

### 7. 不想再查看、或要刪除資料
- 不想再查看：「👤 我的」→「解除綁定」（孩子的紀錄不受影響）。
- 要刪除帳號或孩子的全部資料、或資料有錯要更正：請聯絡團長。

## 三、服務員篇

### 1. 加入
1. 打開網站 → 右上角「🔑 登入」→「**註冊新帳號**」→ 選身分「**服務員**」。
2. 填你的**姓名**（會顯示在管理員名單）、**帳號**、**密碼**。自己的孩子也在團裡的話，勾「我也有孩子在團裡」並填孩子姓名（會多一步個資說明）。
3. 送出後顯示「等待團長審核」。團長核准後重新登入，就會直接進後台。

（已經用家長身分註冊過的人，不用重新註冊，請團長幫你把帳號調整成服務員。）

（拿到團長給的**邀請碼**時：「註冊新帳號 → 我有綁定碼」輸入邀請碼，註冊完就直接是服務員，不用等審核。其他分團的服務員登入後會看到「分團功能準備中」。）

> 🔒 **改密碼、改稱呼**：後台「👤 我的帳號與 LINE」（手機在「☰ 更多」裡，電腦版在左側選單）→「🔒 修改密碼」。

> **選單名稱對照（2026-11-15 整理）**：「帳號申請」＝原本的註冊審核；「總覽」裡切換進程／出席；「行事曆」裡切換集會行事曆／年度出席；「帳號與權限」裡切換管理員／所有帳號（原本的帳號管理）；「列印紙本」＝原本的列印簽核單。功能都沒有變，只是合併與改名。

### 2. 精簡版後台首頁與 8 大選單分類
後台首頁已精簡為**直接顯示「🛠️ 今天要做的事」**（今日集會、待辦快捷鍵、待頒章、可入團體驗者與系統提示），不再把公開網站介紹疊在上方；需要對照前台時，直接點選單的「📖 查看公開網站」即可。

後台導覽已收斂為 **8 個主要入口**（點入後於頁面上方透過分段分頁切換子功能，並依總團「權限設定」自動隱藏無權限的分頁）：

| 選單入口 | 包含的子分頁與功能 |
|---|---|
| 🏠 **首頁** | 今日集會、待辦清單、系統提示（總團／管理員另含「全團總覽」） |
| 📋 **集會與點名** | 點名 ／ 行事曆 ／ 年度出席 |
| ✅ **進程與頒章** | 簽核 ／ 頒章 ／ 進程總覽 ／ 列印簽核單（依分團進程模組顯示） |
| 👥 **團員與幹部** | 團員名單 ／ 帳號申請 ／ 小隊與小隊輔 ／ 出席總覽 |
| 📣 **公告與活動** | 公佈欄 ／ 活動報名與繳費 |
| 🛡️ **帳號與權限** | 分團管理員 ／ 所有帳號 ／ 分團身分 ／ **🎛️ 權限設定（僅總團／管理員）** |
| ⚙️ **團務設定** | 系統與網站內容 ／ 項目管理 ／ 離團個資處理 ／ 備份 ／ **🤝 移交中心（僅總團／管理員）** |
| 👤 **我的帳號與 LINE** | 修改稱呼與密碼、**連結／解除 LINE 通知**（已合併至同一頁） |

### 3. 點名（團集會現場）
1. 「📋 點名」→ 會自動選好**今天的集會**（今天沒有就選最近一場，上方可以換）。
2. 上方選**小隊**（或全團）。
3. 按「**✅ 全部出席**」→ 再把**遲到、請假的**改掉（點一下切換：空白 → 🐾 出席 → ⏰ 遲到 → 🌙 請假 → 空白）。遲到也算出席，只是多一個標記。
4. 按「**儲存點名**」。

> - 沒來也沒請假的，保持空白即可（系統不記錄缺席）。
> - 還沒儲存就離開會跳出提醒。
> - 兩位服務員可以同時點不同小隊，不會互相覆蓋。
> - 羚羊級「參加幼童軍團集會至少 4 次」會在出席滿 4 次時**自動打勾**，不用另外簽。

> 🧪 **體驗者**（還沒入團的小朋友）只出現在一般團集會的點名，名字旁邊有「🧪 體驗」；大活動不列體驗者。照常點出席或請假就好。

### 4. 簽核（小隊一起簽，最常用）
簽核分成三步，畫面下方的按鈕一步一步往下：
1. **① 選小隊** →「下一步：選項目」。
2. **② 選項目**：上方選單選級別或技能章（「⭐ 最近簽過的項目」在最前面），大項多時可以再點大項篩選，勾選這次完成的項目。每個項目下面會顯示「已完成 x／y 位」。
   - **可以跨級簽**：照團集會實際做的內容簽，不用管小狼現在幾級。例如羚羊級的小狼做了椅子，就選「進程・豹級」→ 勞作，簽鐵鎚、鋸子那一項。
3. **③ 選小狼與日期**：預設全選該小隊，沒完成的取消勾選；日期預設今天，可改成過去的日期 →「**送出簽核**」。
4. 送出後會回到第 ② 步，可以接著簽下一批；簽錯了馬上按「**↩️ 復原剛才這一批**」。

### 5. 單人簽核、撤銷
「👥 團員」→ 點團員 → 上方切換「進程／技能章／家長帳號」→ 展開級別或技能章（編輯、補登、列印、離團、個資處理收在右邊的「⋯」）：
- 勾選未完成的項目 → 選日期 →「簽核勾選的項目」。
- 已完成的項目旁有「撤銷」：服務員**只能撤銷自己簽的**。

### 6. 列印簽核單
「✅ 進程與頒章」→ 上方切換「🖨️ 列印」→ 選級別 → 選小隊或小狼 →「列印」（A4，每位小狼一頁）。

### 7. 連結 LINE 通知
「👤 我的帳號與 LINE」→ 取得 6 位數配對碼 → 手機 LINE 加入 22 團官方帳號 → 在聊天室輸入配對碼 → 收到「已連結」就完成。連結後會收到達標通知，也可以用關鍵字「點名」「可晉級」「快達標」查詢，詳見「[五之二、LINE 官方帳號](#五之二line-官方帳號line)」。

---

### 8. 公佈欄
後台「📣 公告與活動」→「📣 公佈欄」（手機在「☰ 更多」裡）→ 填標題、內容，可以選「連到哪一場集會」和「置頂」→ 發布。
- 公告**不用登入就看得到**，會出現在網站首頁，所以**不要寫孩子的姓名或其他個人資料**。
- 寫錯了按「修改」；不需要了按「下架」（之後可以重新上架）。

### 9. 我是小隊輔
團長把你設成某個小隊的小隊輔之後，你進「點名」「簽核」時會預設選到你的小隊（還是可以切換到其他小隊或全團）。家長會看到孩子的小隊輔姓名。點名畫面上已經標「請假」的，可能是家長自己在網站上先請的假。

## 四、團長篇

團長可以使用服務員的所有功能（見第三篇），另外還有以下功能。

### A. 上線前的一次性設定

**A1. 小隊**：「👥 團員管理」→ 上方切換「🏕️ 小隊」→ 依序新增小隊；可以改名（小狼會一起更新）、▲▼ 調整順序；還有小狼的小隊不能刪除。

**A2. 新增小狼**（家長自己註冊時，會在審核時一併建立，不必先新增）：「👥 團員 → ＋ 新增團員」→ 姓名、小隊（用選的）、**入團日（可填過去日期）** → 儲存。系統會自動產生**綁定碼**。

**A2-1. 一次改很多位（分小隊、改姓名或入團日）**：「👥 團員」→「✏️ 直接編輯」→ 名單變成表格，直接改小隊（下拉選單）、姓名、入團日 → 按下方「💾 儲存」。改過的格子會標黃色；沒儲存就離開會提醒。

**A3. 補登已經拿到的章**（現有團員）：小狼頁 →「📥 補登頒章」→ 選級別或技能章、填頒發日期 → 補登。
- 較低級別沒有紀錄時，系統會問是否一併補登（同一天）。
- 補登會把該級所有項目自動打勾（備註「上線補登」），**不發任何通知**。
- 狼、鹿、豹級的頒發日期會影響下一級「滿 6 個月」的計算，請盡量填準。

**A4. 正在挑戰的級別，補勾已完成的項目**：用單人簽核或小隊簽核，日期填當初完成的日期（見第三篇 4、5）。

**A5. 行事曆**：「📋 集會與點名」→ 上方切換「📅 行事曆」→ 一次貼上整學期，每行一場：
```
2026-11-22 團集會
2026-11-29 露營
2026-12-06
```

### C-2. 網站內容與 LINE 選單

### C-3. 活動報名與繳費紀錄
1. 後台「🎪 活動報名」→「＋ 新增活動」：填名稱、說明、活動日期、**開始報名與結束報名時間**、每人費用。
2. **費用與名額**：
   - 「不同身分不同費用」（選填）：例如童軍 1000、家長 600；空白的身分用每人費用。
   - 「人數上限」：空白＝不限。額滿後再報名的人會**排候補**（家長畫面會顯示「⏳ 候補中」）；有人取消時不會自動遞補，請到名單按「轉正取」。
3. 「報名表的題目」：每位報名的人一定會填姓名和身分別（小狼、稚齡、童軍、家長、服務員）；你可以再加自己的題目，最多 10 題，作答方式有三種：
   - **選擇題（選一個）**：例如「飲食：葷, 素」。
   - **複選題（可以選好幾個）**：例如「參加哪幾天：週六, 週日」。
   - **簡答**。
   選項要另外加錢的，在選項後面寫「+金額」，例如「帳篷：自備, 租帳篷+200」。報名時系統自動算好每一位的應繳金額（身分費用＋加價），報名表上也會顯示預估金額。不可以問電話、地址、身分證、生日，系統會擋。
4. 建立後，**網站首頁會出現「🎪 活動報名」卡片**（所有人都看得到，不用登入；報名中的排最前面，顯示日期、報名期間、費用與剩餘名額），各分團頁只列全團與該分團的活動，家長登入後的首頁也會列出孩子分團的活動。首頁月曆也會標出活動日、開始報名（綠線）、報名截止（紅線）。家長、服務員按「✍️ 報名」→ 登入後直接打開報名表，一次可以幫全家報名。
5. 點進活動可以看**報名名單**（候補的排在最後、顏色較淡）：每一位的應繳金額可以改，收到錢就勾「已繳」，按「儲存繳費紀錄」。這裡只是記帳，系統不會收款。
6. 可以「下載名單 CSV」、取消某一位的報名、或把活動關閉。
7. **只有 22 團的人可以報名**：團長、服務員，以及孩子在團（或體驗中）的家長。還沒通過審核的帳號看得到活動，但不能報名。
8. **活動結束後隔天，網站上的報名資料會自動清除**，只留存檔試算表；存檔試算表請你自己在雲端硬碟封存（系統不會刪它）。結束的活動不能再修改。
9. **每個活動有一份獨立的 Google 試算表存檔**：建立活動時自動產生，放在你雲端硬碟的「幼童軍活動報名存檔」資料夾（只有你看得到）。裡面有報名名單（含取消的）、每一位的應繳金額與是否已繳、以及人數與金額統計；有人報名、取消或你登記繳費後會自動更新。名單頁按「📄 開啟存檔試算表」就能打開。**請不要直接改那份試算表**——它是存檔，改了不會寫回系統，下次更新也會被蓋掉；要改請在後台改。

### C-4. 章的圖片
系統已經內建一套圖：羚羊、狼、鹿、豹是照布章樣式畫的 Q 版菱形圖，技能章是依分類顏色的三角形圖。想換成官方圖檔或照片，再照下面上傳即可，上傳的會優先顯示。
「📚 項目管理」→ 選級別或技能章 →「🖼️ 上傳這個章的圖片」。請用官方的章圖，或用手機拍布章；系統會自動縮小。上傳後，網站上這個章的圖示都會換成圖片；小狼頒章後，小狼頁的「🏅 已獲得的章」和家長畫面都會顯示。沒上傳的維持表情符號。

### D. 升團或離團（附錄第 80 點）
- **升團**：團員頁 →「⋯」→「⬆️ 升團到（下一個分團）」→ 選升團日（例如五月團慶）。順序是稚齡 → 小狼 → 童軍 → 行義 → 羅浮。這位團員會移到新分團的名單：團員ID、家長綁定不變，之前的進程、章、出席都保留，新分團的團長在團員頁「📜 之前分團的紀錄」看得到；小隊清空、職務卸任，新分團的入團日＝升團日。只有原分團的團長（或最高管理員、總團切到原分團）可以按。
- **童軍升行義**：兩個分團共用同一套進程，已完成的項目和章照樣算，行義團長接著簽高級、獅級……。
- **離團**：「⋯」→「標記離團」→ 選離開原因（不續團／退團／其他）→ 填離團日。綁定碼立即失效、職務自動卸任，紀錄保留。

### D-1. 小隊輔
「🏕️ 小隊設定」→ 每個小隊右邊的「小隊輔」→ 勾選一位或多位團長、服務員 → 儲存。小隊輔點名、簽核時會預設帶到自己的小隊；家長看得到小隊輔姓名。這只是方便，不會限制服務員只能處理自己的小隊。

### D-2. 正副小隊長
小狼頁 →「⋯」→「🎗️ 設定職務」→ 選小隊長、副小隊長或隊員 → 填開始日。
- 狼級以上才能擔任；**小隊裡沒有狼級以上的小狼時，羚羊級也可以**。
- 每個小隊正、副各一位；換人時系統會先問你，確定後原本那位自動卸任。
- 換小隊、升團、離團時會自動卸任。小狼頁的「🎗️ 職務紀錄」看得到每一段任期。

### D-3. 批次匯入名單
「👥 團員 → 📥 批次匯入」→ 貼上名單，每行一位：`姓名 小隊 入團日`（用空白或逗號分開；小隊、入團日可以不填，入團日預設今天）→ 匯入。只要有一行有錯就整批不匯入，並告訴你哪一行。小隊要先在「小隊設定」建立。每位都會自動產生綁定碼。

### E. 綁定碼管理
小狼頁「🔑 綁定碼」區：
- 「🔄 重新產生」：舊碼立即失效（已綁定的家長不受影響）。
- 下方列出已綁定的家長帳號，可以「解除」某一個綁定。

### F. 家長忘記密碼
「🛡️ 帳號與權限」→ 上方切換「🔑 所有帳號」→ 搜尋家長 →「管理」→「產生重設密碼臨時碼」→「📋 複製」→ 用 LINE 傳給家長。
同一頁也可以**停用**或**刪除**帳號（刪除帳號不影響孩子的資料）。

### G. 個資處理（離團後或家長要求時）
「⚙️ 團務設定」→ 上方切換「🔐 個資處理」→ 選小狼 → 選方式 →「預覽會影響幾列資料」→ 輸入小狼姓名確認 → 執行。
- **匿名化**：姓名改成「已離團小狼＋編號」、刪除綁定；進程與出席紀錄保留供統計。
- **完全刪除**：刪除這位小狼在所有分頁的資料。
- 執行後可選「立即刪除所有舊備份並重新備份」。
- 離團超過設定天數（預設 180 天）還沒處理，後台首頁會提醒。
- **活動報名不在個資處理範圍內**：還沒結束的活動，報名表上可能還有這個孩子的名字（家長自己填的，系統無法確定是同一人）。處理方式：① 到「公告與活動 → 活動」打開那個活動的報名名單，按那一筆的「取消報名」（名單上就不會再出現）；② 姓名仍會留在系統的「活動報名」分頁和該活動的存檔試算表，**活動結束後系統會自動清除**。家長要求立刻刪除時，再到試算表選單「顯示全部分頁」→「活動報名」分頁，以及該活動的存檔試算表，手動刪掉那一列（刪整列，不要動其他列）。

## 五、常見問題

**Q：家長說輸入綁定碼一直錯誤？**
A：姓名要和團裡登記的一模一樣（含同音字）；綁定碼可能已用完次數或被重新產生過。到小狼頁確認綁定碼與剩餘次數，必要時「重新產生」。錯太多次會暫時鎖住，稍後再試。

**Q：網頁看起來是舊的？**
A：按 `Ctrl + Shift + R`（電腦）或關掉分頁重新打開（手機）。

**Q：畫面顯示「登入已過期」？**
A：重新登入即可，登入後會回到剛才的畫面。

**Q：簽錯了怎麼辦？**
A：剛送出的整批按「復原」；單一項目到小狼頁按「撤銷」。

**Q：頒章日期填錯？**
A：小狼頁 →「修改頒章」。

**Q：服務員看不到某些功能？**
A：服務員只能點名、簽核、看名單與總覽、列印；頒章、名單管理、帳號、個資等只有團長可以做。需要時由團長在「管理員」把對方改成團長。

**Q：家長看得到別的孩子嗎？**
A：不行。家長只看得到自己綁定的孩子；公開的進程與技能章查詢頁不含任何孩子的資料。

## 五之一、後台的「設定」與「項目管理」（團長）
- **⚙️ 設定**：「⚙️ 團務設定」→「⚙️ 系統與網站」。晉級所需出席次數、剛入團所需出席次數、晉級間隔月數、每週備份等，改完按「儲存設定」立即生效；超出範圍會擋下。下方可以修改**個資說明**，儲存後變成新的一版，已綁定的家長下次登入要重新同意。
- **📝 項目管理**：「⚙️ 團務設定」→ 上方切換「📚 項目管理」。選進程或技能章 → 選級別或章：
  - ✏️ 修改文字（項目ID 不變，已完成紀錄保留）、▲▼ 調整順序、停用／重新啟用（不會刪除）。
  - ＋ 新增一項、＋ 新增大項、大項改名；技能章可「＋ 新增技能章」、改章名（已有頒章紀錄的章不能改名）。
  - 📋 細項：新增、修改、停用本團細項（分組、內容、通過標準、生活應用）。
  - 新增、停用、重新啟用會先跳出「這會讓 N 位團員……」的影響預覽，按確定才執行。
  - 項目管理只管**目前分團**的項目（稚齡團長管稚齡的，小狼團長管小狼的）。匯出 CSV 也只有目前分團。
  - 「🔍 檢查項目總表」看試算表裡有問題的列；「⬇️ 匯出 CSV」下載備份；「🔄 重新載入」在你直接改過試算表後使用。

回覆不會用掉每月推播額度。前三個只有已連結的團長與服務員會收到名單，其他人輸入不會有回應。

### 6. 推播額度
- 官方帳號每月有免費推播則數，**每位收件人各算一則**。目前只有「達標通知」會用到，而且只傳給已連結的管理員，人數很少。
- 關鍵字的回覆不算額度。
- 家長推播目前不做（要用到大量額度、還要家長重新同意個資說明），之後要做請先跟維護的人討論。

### 7. 常見問題
- **按了「安裝 LINE 圖文選單」出現「安裝失敗」**：多半是 token 錯了或過期；到 LINE Developers 重新發一組 Channel access token，貼到指令碼屬性後再按一次。
- **輸入關鍵字沒有回應**：先確認自己已完成連結（第 3 點）；全部人都沒回應時，請確認 LINE Developers 的 Webhook 網址是「部署網址?key=WEBHOOK_KEY」且「Use webhook」已開啟，並且 Apps Script 已部署最新版本。
- **後台首頁出現「有 N 則通知未送達」**：通常是有人封鎖了官方帳號或 token 失效，請檢查。
- **選單還是舊的**：手機上把聊天室關掉再打開；還是舊的就再按一次安裝。

## 六、什麼時候需要打開 Google 試算表

平常**不需要**：設定、項目、細項、個資說明都可以在網頁後台改。打開試算表時只會看到下表這 5 個分頁，其他系統分頁已經隱藏起來（資料都在）。要查紀錄（例如操作日誌、出席紀錄）時，用上方選單「🐺 幼童軍系統 → 顯示全部分頁」，查完再按「只顯示需要編輯的分頁」收起來。

只有以下情況需要打開：

| 情況 | 分頁 | 注意 |
|---|---|---|
| 取得團長預設帳號 admin（忘記密碼時重設） | 上方選單「🐺 幼童軍系統 → 🔑 團長預設帳號（admin）」 | 密碼只顯示在視窗，請抄下來 |
| 把某個帳號設為團長（最高權限） | 上方選單「🐺 幼童軍系統 → 把帳號設為團長」 | 對方要先在網站註冊好 |
| 新增或卸下最高管理員（最多 3 位） | 上方選單「🐺 幼童軍系統 → 👑 新增最高管理員／👑 卸下最高管理員」 | 對方要先在網站註冊好；至少保留一位 |
| 修改個資說明 | 告知同意內容 | 已經有家長同意後，請**新增一列、版本 +1**，不要改舊的 |
| 修改項目文字、停用項目 | 項目總表 | **不要改 A 欄項目ID、不要刪整列**；停用請把「啟用」改成「否」 |
| 寫技能章的說明文字 | 級別與章說明 | 「說明」欄 |
| 修改本團細項、通過標準、生活應用 | 進程細項 | A 欄填官方項目ID（照項目總表）；通過標準與生活應用只要填在每組第一列；停用請把「啟用」改成「否」。改完約 5 分鐘後公開查詢頁才會更新 |
| 調整系統數值（晉級間隔、出席門檻等） | 設定 | 填錯會自動用預設值，後台首頁會提示 |

**不要手動改**：帳號、登入工作階段、綁定紀錄、管理員、管理員邀請、完成紀錄、頒章紀錄、出席紀錄、額外出席、通知紀錄、失敗紀錄、操作日誌、權限設定（請由後台「權限設定」調整；`設定` 中的 `最高管理員帳號ID` 也請由後台「移交中心」更新）。
