## 一、網站有哪些頁面

| 頁面 | 誰可以用 | 網址 |
|---|---|---|
| 🏠 首頁（打開網站的第一頁；按左上角「22團幼童軍」也會回來） | 任何人，不用登入 | `…/web/#home` |
| 🗺️ 進程查詢 | 任何人，不用登入 | `…/web/#progress` |
| 🎖️ 技能章查詢 | 任何人，不用登入 | `…/web/#badges` |
| 🏕️ 家長畫面 | 家長（登入） | 登入後自動進入 |
| 🛠️ 管理員後台 | 團長、服務員（登入） | 登入後自動進入 |

**只有一個登入入口**（上方導覽列的「登入」）：系統會依帳號自動帶你到對的地方。同時是家長又是服務員的人，會先進後台，右上角「家長畫面」可以切換。

## 二、家長篇

### 1. 第一次使用：註冊（約 2 分鐘）
需要準備：**孩子的全名**。

1. 打開網站 → 右上角「🔑 登入」→「**註冊新帳號**」。
2. 選身分「**家長**」。（同時是家長和服務員的話選「服務員」，或先選家長，之後請團長幫你調整。）
3. 填**孩子的姓名**（有兩個以上孩子在團裡，按「＋ 再加一位孩子」）、你的**稱呼**（例如「王小明媽媽」）、**帳號**（4～20 個英文字母、數字或底線，例如 `xiaoming_mom`）、**密碼**（至少 8 個字）。
4. 閱讀**個資說明** → 勾選同意 →「同意並送出申請」。
5. 畫面會顯示「**等待團長審核**」。團長核准後，再登入（或按「重新整理」）就能看到孩子的冒險紀錄。

> 爸爸、媽媽可以各自註冊同一個孩子，團長審核時會把你們連到同一位小狼。
> 按「不同意」不會建立帳號，也不會留下任何資料。
> 如果團長給了你「綁定碼」，也可以用登入頁的「我有綁定碼」註冊，不需要等審核。

### 2. 之後登入
帳號＋密碼 → 勾「記住我」，這台手機下次就不用再登入。

### 3. 看孩子的進度（3 個分頁；手機在螢幕下方、電腦在上方）
| 分頁 | 看什麼 |
|---|---|
| 🏠 **首頁** | 孩子的基本資料、這一級的進度、技能章數、出席率；**下一步挑戰**（接下來要完成的任務）；下次集會；正在挑戰的、已經拿到的章 |
| 🗺️ **進度** | 上方可以切換三種：**闖關**（剛入團→羚羊→狼→鹿→豹，點關卡看每一項任務、完成日期、晉級條件、📋 本團細項，可列印簽核單）、**徽章**（技能章收藏冊，點徽章看合格標準）、**出席**（出席率、每次集會的紀錄） |
| 👤 **我的** | 帳號、修改稱呼與密碼、綁定的孩子、新增孩子、解除綁定、個資說明、登出 |

**體驗者**：還沒入團的孩子，首頁會顯示「一般團集會 x／4 次」。參加滿 4 次一般團集會（大活動不算）後，由團長轉為入團，之後開始挑戰「🌱 剛入團」。

**狀態說明**
- 🔒 未開始／🔥 挑戰中：還有任務沒完成。
- ⏳ 等待頒發：任務都完成了，「項目已全部完成，等待團長評核頒發」。
- 🏅 已拿到：團長已頒發，會顯示頒發日期。

> 孩子完成任務後，要在團集會時請團長或服務員**簽核**，網站上的星星才會亮起來。
> 進程是依團集會實際完成的內容簽核，所以孩子有時會先完成比目前級別更高的任務（例如羚羊級先做了豹級的木工），那一級會先顯示「🔥 挑戰中」，這是正常的。
> 家長在紙本簽名的項目，由團長登記到系統後才會亮起來。

### 3-1. 公告、接下來的集會與請假
- **公佈欄**：團裡的公告會出現在網站首頁（不用登入也看得到）和你登入後的首頁。
- **接下來的集會**：「🗺️ 進度 → 🐾 出席」會列出接下來的集會（日期、名稱、備註）。
- **線上請假**：不能來的那一場按「請假」，點名時服務員就會看到；計畫改變可以按「取消」。已經過了的集會、或已經點名為出席的，請直接聯絡團長或服務員。請假不算出席。
- 首頁也會顯示孩子的小隊輔是誰，以及孩子是不是小隊長、副小隊長。

### 4. 有第二個孩子
「👤 我的」→「＋ 新增孩子」→ 填孩子姓名 → 勾選同意 →「送出申請」。團長核准後，畫面上方可以切換孩子。

### 5. 忘記密碼或帳號
請**聯絡團長**。團長會用 LINE 傳一組「**臨時碼**」給你：
登入頁 →「忘記密碼？」→ 輸入帳號、臨時碼、新密碼。臨時碼只能用一次，有使用期限。

### 6. 個資說明更新時
團長更新個資說明後，下次登入會請你重新閱讀並同意。

### 7. 不想再查看、或要刪除資料
- 不想再查看：「👤 我的」→「解除綁定」（孩子的紀錄不受影響）。
- 要刪除帳號或孩子的全部資料、或資料有錯要更正：請聯絡團長。

## 三、服務員篇

### 1. 加入
1. 打開網站 → 右上角「🔑 登入」→「**註冊新帳號**」→ 選身分「**服務員**」。
2. 填你的**姓名**（會顯示在管理員名單）、**帳號**、**密碼**。自己的孩子也在團裡的話，勾「我也有孩子在團裡」並填孩子姓名（會多一步個資說明）。
3. 送出後顯示「等待團長審核」。團長核准後重新登入，就會直接進後台。

（已經用家長身分註冊過的人，不用重新註冊，請團長幫你把帳號調整成服務員。）

> 🔒 **改密碼、改稱呼**：後台「☰ 更多 → 👤 我的帳號（改密碼）」（電腦版在左側選單）→「🔒 修改密碼」。

> **選單名稱對照（2026-11-15 整理）**：「帳號申請」＝原本的註冊審核；「總覽」裡切換進程／出席；「行事曆」裡切換集會行事曆／年度出席；「帳號與權限」裡切換管理員／所有帳號（原本的帳號管理）；「列印紙本」＝原本的列印簽核單。功能都沒有變，只是合併與改名。

### 2. 後台首頁與分頁
> 後台首頁的上半部和大家看到的網站首頁一樣（公佈欄、進程與技能章查詢）；往下捲是「後台：今天要做的事」（點名、簽核、待辦、系統提示）。

後台首頁是「今天要做的事」：今天的集會、四個大按鈕（開始點名、簽核進程、頒章、帳號申請，有待辦會顯示紅色數字）、待辦清單（待頒章、可入團的體驗者、快達標）。手機的 5 個分頁在螢幕下方；「更多」裡的功能分成「每次集會／名單／設定／系統」四組。

> 版面：電腦上分頁在最上方一排，後台在左側選單直接列出全部功能（不用再點「☰ 更多」）；手機上分頁在標題下方一排。

| 分頁 | 做什麼 |
|---|---|
| 🏠 首頁 | 今天的集會（去點名、去簽核）、待頒章、快達標 |
| 📋 點名 | 團集會點名 |
| ✅ 簽核 | 記錄小狼完成的進程與技能章項目 |
| 🐺 小狼 | 名單、每位小狼的詳細進度 |
| ☰ 更多 | 進程總覽、出席總覽、列印簽核單、連結 LINE 通知 |

### 3. 點名（團集會現場）
1. 「📋 點名」→ 會自動選好**今天的集會**（今天沒有就選最近一場，上方可以換）。
2. 上方選**小隊**（或全團）。
3. 按「**✅ 全部出席**」→ 再把**請假的**點成 🌙（點一下切換：空白 → 🐾 出席 → 🌙 請假 → 空白）。
4. 按「**儲存點名**」。

> - 沒來也沒請假的，保持空白即可（系統不記錄缺席）。
> - 還沒儲存就離開會跳出提醒。
> - 兩位服務員可以同時點不同小隊，不會互相覆蓋。
> - 羚羊級「參加幼童軍團集會至少 4 次」會在出席滿 4 次時**自動打勾**，不用另外簽。

> 🧪 **體驗者**（還沒入團的小朋友）只出現在一般團集會的點名，名字旁邊有「🧪 體驗」；大活動不列體驗者。照常點出席或請假就好。

### 4. 簽核（小隊一起簽，最常用）
簽核分成三步，畫面下方的按鈕一步一步往下：
1. **① 選小隊** →「下一步：選項目」。
2. **② 選項目**：上方選單選級別或技能章（「⭐ 最近簽過的項目」在最前面），大項多時可以再點大項篩選，勾選這次完成的項目。每個項目下面會顯示「已完成 x／y 位」。
   - **可以跨級簽**：照團集會實際做的內容簽，不用管小狼現在幾級。例如羚羊級的小狼做了椅子，就選「進程・豹級」→ 勞作，簽鐵鎚、鋸子那一項。
3. **③ 選小狼與日期**：預設全選該小隊，沒完成的取消勾選；日期預設今天，可改成過去的日期 →「**送出簽核**」。
4. 送出後會回到第 ② 步，可以接著簽下一批；簽錯了馬上按「**↩️ 復原剛才這一批**」。

### 5. 單人簽核、撤銷
「🐺 小狼」→ 點小狼 → 上方切換「進程／技能章／家長帳號」→ 展開級別或技能章（編輯、補登、列印、離團、個資處理收在右邊的「⋯」）：
- 勾選未完成的項目 → 選日期 →「簽核勾選的項目」。
- 已完成的項目旁有「撤銷」：服務員**只能撤銷自己簽的**。

### 6. 列印簽核單
「☰ 更多 →🖨️ 列印簽核單」→ 選級別 → 選小隊或小狼 →「列印」（A4，每位小狼一頁）。

### 7. 連結 LINE 通知
「☰ 更多 → 💬 連結 LINE 通知」→ 取得 6 位數配對碼 → 用手機 LINE 加入「22團幼童軍進程系統」官方帳號 → 在聊天室輸入配對碼 → 收到「已連結」就完成。
（達標通知功能將在後續版本啟用。）

---

### 8. 公佈欄
後台「📣 公佈欄」（手機在「更多」裡）→ 填標題、內容，可以選「連到哪一場集會」和「置頂」→ 發布。
- 公告**不用登入就看得到**，會出現在網站首頁，所以**不要寫孩子的姓名或其他個人資料**。
- 寫錯了按「修改」；不需要了按「下架」（之後可以重新上架）。

### 9. 我是小隊輔
團長把你設成某個小隊的小隊輔之後，你進「點名」「簽核」時會預設選到你的小隊（還是可以切換到其他小隊或全團）。家長會看到孩子的小隊輔姓名。點名畫面上已經標「請假」的，可能是家長自己在網站上先請的假。

## 四、團長篇

團長可以使用服務員的所有功能（見第三篇），另外還有以下功能。

### A. 上線前的一次性設定

**A1. 小隊**：「☰ 更多 → 🏕️ 小隊設定」→ 依序新增小隊；可以改名（小狼會一起更新）、▲▼ 調整順序；還有小狼的小隊不能刪除。

**A2. 新增小狼**（家長自己註冊時，會在審核時一併建立，不必先新增）：「🐺 小狼 → ＋ 新增小狼」→ 姓名、小隊（用選的）、**入團日（可填過去日期）** → 儲存。系統會自動產生**綁定碼**。

**A2-1. 一次改很多位（分小隊、改姓名或入團日）**：「🐺 小狼」→「✏️ 直接編輯」→ 名單變成表格，直接改小隊（下拉選單）、姓名、入團日 → 按下方「💾 儲存」。改過的格子會標黃色；沒儲存就離開會提醒。

**A3. 補登已經拿到的章**（現有團員）：小狼頁 →「📥 補登頒章」→ 選級別或技能章、填頒發日期 → 補登。
- 較低級別沒有紀錄時，系統會問是否一併補登（同一天）。
- 補登會把該級所有項目自動打勾（備註「上線補登」），**不發任何通知**。
- 狼、鹿、豹級的頒發日期會影響下一級「滿 6 個月」的計算，請盡量填準。

**A4. 正在挑戰的級別，補勾已完成的項目**：用單人簽核或小隊簽核，日期填當初完成的日期（見第三篇 4、5）。

**A5. 行事曆**：「☰ 更多 → 📅 行事曆」→ 一次貼上整學期，每行一場：
```
2026-11-22 團集會
2026-11-29 露營
2026-12-06
```
（名稱可省略，預設「團集會」。）取消的集會按「取消」，不會刪除，已點的名保留但不列入統計。

**A6. 年度出席**：「☰ 更多 → 🎯 年度出席」→ 年度名稱（例如「115學年度」）、開始日、結束日、**應出席總數** → 儲存。
有參加額外活動的小狼，在下方「額外出席次數」替他加上次數。
出席率 =（出席 ＋ 額外出席）÷ 應出席總數（請假不算出席，最多顯示 100%）。

**A7. 邀請服務員**：「☰ 更多 → 👥 管理員」：
- 對方**已有帳號**（例如家長兼服務員）：「從已註冊的帳號指定」→ 搜尋 →「指定」→ 選角色、填姓名。
- 對方**沒有帳號**：最簡單是請他自己「註冊新帳號」選「服務員」，你在「📝 帳號申請」核准（見 A9）。
- 邀請碼功能已經拿掉，不需要再產生任何代碼。

**A8. 個資說明**：試算表「告知同意內容」第 1 版裡的【請填寫】要改成實際內容（團長聯絡方式、保存天數）。

**A9. 審核註冊申請**（家長、服務員自己註冊後）：後台首頁會出現「📝 有 N 筆註冊申請等待審核」→「前往審核」（或選單「📝 帳號申請」）：
- **孩子**：選「新增小狼（直接入團）」（可修正姓名錯字、選小隊、填入團日）、「🧪 新增為體驗者」（還沒入團的新朋友）或「連結到現有小狼」（爸爸媽媽各自申請同一個孩子時，系統會提示同名小狼）→「✅ 核准」。
- **服務員**：確認顯示姓名 →「✅ 核准為服務員」。
- 不認識的申請 →「退回」，可以寫原因，申請人看得到。
- 家長兼服務員先選了「家長」：用「👥 管理員 → 從已註冊的帳號指定」把他設成服務員。
- 舊方式仍可用：小狼頁「📋 複製給家長的說明文字」把綁定碼傳給家長，家長用「我有綁定碼」註冊，不需審核。

**A11. 晉級出席次數**：試算表「設定」分頁：
- 「剛入團所需出席次數」＝ **4**（入團後出席 4 次才能頒黃領巾）。
- 「晉級所需出席次數」＝ **8**（羚羊、狼、鹿、豹每一級：上一級頒發後再出席 8 次，請假不算）。舊系統這一格原本是 0，請改成 8。

**A11-0. 體驗者**：還沒入團的小朋友先當「體驗者」。
- 「🐺 小狼 → 🧪 新增體驗者」→ 姓名、小隊、體驗開始日 → 儲存。家長之後自己註冊時，在「📝 帳號申請」選「連結到現有小狼」。
- 行事曆裡的**大活動**（露營、聯團等）請標成「大活動」：名稱有「大活動」三個字會自動標，也可以在行事曆按「設為大活動」。大活動不算體驗次數，點名也不列體驗者。
- 一般團集會出席滿 4 次，後台首頁「🧪 體驗者」會顯示「✅ 可以入團」→ 點進去按「🎉 轉為入團」（入團日預設今天）。入團後開始挑戰剛入團，剛入團還要再出席 4 次。

**A11-1. 剛入團（黃領巾）**：新入團的小狼先挑戰「剛入團」5 項，完成並出席滿 4 次後，用「🏅 頒章」頒發剛入團（場合可寫「黃領巾」）。已經拿到羚羊以上的小狼不用補，系統視為已通過。

**A12. 家長認證的項目**：家長在紙本簽名後，由你用單人簽核登記，備註填「家長簽名」。

**A10. 備份**（setup 已自動開啟每週備份）：照 `docs/SETUP.md` 第 7 步設定一次，之後每週日自動備份。

### B. 每次團集會的流程
1. 集會前：後台首頁看「待頒章」「快達標」。
2. 集會中：📋 **點名** → ✅ **簽核**今天完成的項目。
3. 有晉級儀式：🏅 **頒章**（見 C）。

### C. 頒章
- 後台首頁「待頒章」→「🏅 前往頒章」，或小狼頁該級別的「🏅 頒章」。
- 可一次勾選多位小狼、多個級別或技能章，共用**頒發日期**（儀式當天，預設今天）與**頒發場合**（例如「11 月團集會」）。
- 未來日期、或還沒滿晉級間隔／出席次數時，系統會請你再確認一次。
- **修改**：小狼頁該級別 →「修改頒章」（日期、場合、備註）。
- **撤銷**：小狼頁 →「撤銷頒章」（進程級別會退回上一級）。

### C-1. 誰可以設定團長（最高權限在 admin）
- **刪除小狼**（「個資處理 → 完全刪除」）也只有 admin 可以；其他團長只能匿名化。名單「直接編輯」是團長才有，服務員沒有。
- **admin 帳號**是最高權限：只有用 admin 登入，才能在「👥 帳號與權限」把人設成團長、把團長改回服務員、或移除團長。
- 其他團長可以做所有團務（頒章、審核、設定……），也可以指定、移除**服務員**，但動不了團長，也動不了 admin。
- admin 帳號不能被任何人停用、刪除或改密碼；忘記密碼時打開試算表 → 選單「🐺 幼童軍系統 → 🔑 團長預設帳號（admin）」重設。
- 所以 admin 的密碼請只有你自己知道。

### C-2. 網站內容與 LINE 選單
- 「⚙️ 系統設定 → 🌐 網站內容」可以改三樣東西：**了解幼童軍**（團的介紹、怎麼加入、聯絡方式）、**活動時間說明**（固定的時間地點）、**FB 網址**。儲存後網站立即更新。
- 網站首頁有**月曆**，會自動顯示行事曆裡的集會（團集會藍色、大活動黃色）。行事曆的集會名稱與備註現在是公開的，請不要寫個人資料。
- LINE 官方帳號下方的六個按鈕都是連到網站：公佈欄、進程查詢、技能章查詢、了解幼童軍、活動時間、22團 FB。設定方式見 `docs/SETUP.md` 第 12 節。

### D. 小狼升團或離團
小狼頁 →「⋯」→「標記離團」→ 選原因：**🎓 升團**（升上童軍團、畢業）或**離團**（中途離開）→ 填日期。兩種都會讓綁定碼立即失效、職務自動卸任，紀錄保留；名單可以用「升團」「離團」分開篩選。

### D-1. 小隊輔
「🏕️ 小隊設定」→ 每個小隊右邊的「小隊輔」→ 勾選一位或多位團長、服務員 → 儲存。小隊輔點名、簽核時會預設帶到自己的小隊；家長看得到小隊輔姓名。這只是方便，不會限制服務員只能處理自己的小隊。

### D-2. 正副小隊長
小狼頁 →「⋯」→「🎗️ 設定職務」→ 選小隊長、副小隊長或隊員 → 填開始日。
- 狼級以上才能擔任；**小隊裡沒有狼級以上的小狼時，羚羊級也可以**。
- 每個小隊正、副各一位；換人時系統會先問你，確定後原本那位自動卸任。
- 換小隊、升團、離團時會自動卸任。小狼頁的「🎗️ 職務紀錄」看得到每一段任期。

### D-3. 批次匯入名單
「🐺 小狼 → 📥 批次匯入」→ 貼上名單，每行一位：`姓名 小隊 入團日`（用空白或逗號分開；小隊、入團日可以不填，入團日預設今天）→ 匯入。只要有一行有錯就整批不匯入，並告訴你哪一行。小隊要先在「小隊設定」建立。每位都會自動產生綁定碼。

### E. 綁定碼管理
小狼頁「🔑 綁定碼」區：
- 「🔄 重新產生」：舊碼立即失效（已綁定的家長不受影響）。
- 下方列出已綁定的家長帳號，可以「解除」某一個綁定。

### F. 家長忘記密碼
「☰ 更多 → 🔑 帳號管理」→ 搜尋家長 →「管理」→「產生重設密碼臨時碼」→「📋 複製」→ 用 LINE 傳給家長。
同一頁也可以**停用**或**刪除**帳號（刪除帳號不影響孩子的資料）。

### G. 個資處理（離團後或家長要求時）
「☰ 更多 → 🔐 個資處理」→ 選小狼 → 選方式 →「預覽會影響幾列資料」→ 輸入小狼姓名確認 → 執行。
- **匿名化**：姓名改成「已離團小狼＋編號」、刪除綁定；進程與出席紀錄保留供統計。
- **完全刪除**：刪除這位小狼在所有分頁的資料。
- 執行後可選「立即刪除所有舊備份並重新備份」。
- 離團超過設定天數（預設 180 天）還沒處理，後台首頁會提醒。

### H. 其他總覽
- 「📊 總覽」（進程）：小狼 × 各級（剛入團～豹）完成度。
- 「📊 總覽」→ 切到「🐾 出席」：小狼 × 每次集會，可篩選日期區間與小隊。
- 兩個總覽都有「⬇️ 下載 CSV」，下載後用 Excel 或 Google 試算表開啟（依目前選的小隊）。

### I. 每學期／每年要做的事
| 時機 | 要做的事 |
|---|---|
| 每學期開始 | 行事曆貼上新學期的集會 |

## 五、常見問題

**Q：家長說輸入綁定碼一直錯誤？**
A：姓名要和團裡登記的一模一樣（含同音字）；綁定碼可能已用完次數或被重新產生過。到小狼頁確認綁定碼與剩餘次數，必要時「重新產生」。錯太多次會暫時鎖住，稍後再試。

**Q：網頁看起來是舊的？**
A：按 `Ctrl + Shift + R`（電腦）或關掉分頁重新打開（手機）。

**Q：畫面顯示「登入已過期」？**
A：重新登入即可，登入後會回到剛才的畫面。

**Q：簽錯了怎麼辦？**
A：剛送出的整批按「復原」；單一項目到小狼頁按「撤銷」。

**Q：頒章日期填錯？**
A：小狼頁 →「修改頒章」。

**Q：服務員看不到某些功能？**
A：服務員只能點名、簽核、看名單與總覽、列印；頒章、名單管理、帳號、個資等只有團長可以做。需要時由團長在「管理員」把對方改成團長。

**Q：家長看得到別的孩子嗎？**
A：不行。家長只看得到自己綁定的孩子；公開的進程與技能章查詢頁不含任何孩子的資料。

## 五之一、後台的「設定」與「項目管理」（團長）
- **⚙️ 設定**：「更多 → ⚙️ 設定」。晉級所需出席次數、剛入團所需出席次數、晉級間隔月數、每週備份等，改完按「儲存設定」立即生效；超出範圍會擋下。下方可以修改**個資說明**，儲存後變成新的一版，已綁定的家長下次登入要重新同意。
- **📝 項目管理**：「更多 → 📝 項目管理」。選進程或技能章 → 選級別或章：
  - ✏️ 修改文字（項目ID 不變，已完成紀錄保留）、▲▼ 調整順序、停用／重新啟用（不會刪除）。
  - ＋ 新增一項、＋ 新增大項、大項改名；技能章可「＋ 新增技能章」、改章名（已有頒章紀錄的章不能改名）。
  - 📋 細項：新增、修改、停用本團細項（分組、內容、通過標準、生活應用）。
  - 新增、停用、重新啟用會先跳出「這會讓 N 位小狼……」的影響預覽，按確定才執行。
  - 「🔍 檢查項目總表」看試算表裡有問題的列；「⬇️ 匯出 CSV」下載備份；「🔄 重新載入」在你直接改過試算表後使用。

## 五之二、LINE 通知（團長、服務員）
- 先在後台「💬 連結 LINE 通知」取得配對碼，到官方帳號聊天室輸入，完成連結。
- **達標通知**：有小狼達標（可以頒章）時，所有已連結的管理員會收到一則 LINE，按「前往頒章」會打開網頁的頒章畫面（團長）。同一位小狼同一個章只通知一次；超過 14 天還沒頒會再提醒一次（天數在「⚙️ 設定」改，填 0 不提醒）。
- **在聊天室輸入關鍵字**：「可晉級」→ 達標未頒章名單；「快達標」→ 快達標名單；「進度」→ 網站連結。前兩個只有已連結的管理員會得到回覆。
- 家長不會收到任何 LINE 訊息。
- 後台首頁出現「有 N 則通知未送達」：通常是有人封鎖了官方帳號或 token 失效，請檢查。

## 六、什麼時候需要打開 Google 試算表

平常**不需要**：設定、項目、細項、個資說明都可以在網頁後台改。打開試算表時只會看到下表這 5 個分頁，其他系統分頁已經隱藏起來（資料都在）。要查紀錄（例如操作日誌、出席紀錄）時，用上方選單「🐺 幼童軍系統 → 顯示全部分頁」，查完再按「只顯示需要編輯的分頁」收起來。

只有以下情況需要打開：

| 情況 | 分頁 | 注意 |
|---|---|---|
| 取得團長預設帳號 admin（忘記密碼時重設） | 上方選單「🐺 幼童軍系統 → 🔑 團長預設帳號（admin）」 | 密碼只顯示在視窗，請抄下來 |
| 把某個帳號設為團長（最高權限） | 上方選單「🐺 幼童軍系統 → 把帳號設為團長」 | 對方要先在網站註冊好 |
| 修改個資說明 | 告知同意內容 | 已經有家長同意後，請**新增一列、版本 +1**，不要改舊的 |
| 修改項目文字、停用項目 | 項目總表 | **不要改 A 欄項目ID、不要刪整列**；停用請把「啟用」改成「否」 |
| 寫技能章的說明文字 | 級別與章說明 | 「說明」欄 |
| 修改本團細項、通過標準、生活應用 | 進程細項 | A 欄填官方項目ID（照項目總表）；通過標準與生活應用只要填在每組第一列；停用請把「啟用」改成「否」。改完約 5 分鐘後公開查詢頁才會更新 |
| 調整系統數值（晉級間隔、出席門檻等） | 設定 | 填錯會自動用預設值，後台首頁會提示 |

**不要手動改**：帳號、登入工作階段、綁定紀錄、管理員、管理員邀請、完成紀錄、頒章紀錄、出席紀錄、額外出席、通知紀錄、失敗紀錄、操作日誌。
