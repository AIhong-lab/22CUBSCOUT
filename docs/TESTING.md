# 手動測試清單（TESTING）

> 範圍見 SPEC.md 第十一節；階段 4A 補到足以上線，階段 6 定稿。
> 測試一律使用虛構姓名（例如「測試小狼甲」），不得使用真實名單。
> 自動測試：`npm test`（純邏輯＋模擬試算表後端）、`npm run test:web`（模擬手機瀏覽器跑家長端流程）。
> 以下是**必須在真實手機、真實 Google 試算表**上做的檢查，打勾表示已實測。

## 公開頁面（不用登入）
- [ ] 沒登入打開網站，先看到附說明的首頁；三個按鈕分別到進程查詢、技能章查詢、登入
- [ ] 進程查詢與技能章查詢是兩頁，網址分別是 `#progress`、`#badges`，分享到 LINE 點開會直接到該頁
- [ ] 兩頁各自的搜尋正常；在試算表停用某項目，5 分鐘內不再顯示
- [ ] 已登入的家長打開網站直接進自己孩子的頁面；「我的」頁可回到公開頁面
- [ ] 查詢頁看不到任何孩子的名字或進度

## 試算表分頁（重跑 setup 後可測）
- [ ] 重跑 `setup()` 後只看得到 5 個分頁：項目總表、進程細項、級別與章說明、設定、告知同意內容。
- [ ] 選單「🐺 幼童軍系統 → 顯示全部分頁」全部出現；「只顯示需要編輯的分頁」再收起來。
- [ ] 分頁隱藏時，網站登入、點名、簽核照常運作。

## 進程細項（重跑 setup 後可測）
- [ ] 重跑 `setup()` 後試算表多一個「進程細項」分頁，約 375 列；其他分頁內容沒變。
- [ ] 進程查詢 → 羚羊級第 1 項下面有「📋 本團細項 4 條」，點開看得到細項、通過標準、生活應用。
- [ ] 在「進程細項」把一列的「啟用」改成「否」，5 分鐘後進程查詢不再顯示那一條。
- [ ] 家長的闖關地圖、後台小狼頁也看得到本團細項；技能章沒有細項。

## 新的註冊方式（更新後端並重跑 setup 後可測）
- [ ] 無痕視窗：登入 → 註冊新帳號 → 家長 → 填孩子姓名（虛構）→ 同意 → 顯示「等待團長審核」。
- [ ] 團長登入：首頁出現「有 1 筆註冊申請等待審核」→ 前往審核 → 新增小狼（選小隊、入團日）→ 核准。
- [ ] 家長重新整理：看得到孩子。
- [ ] 另一個帳號申請同名孩子 → 審核頁提示同名 → 連結到現有小狼。
- [ ] 註冊服務員 → 團長核准 → 對方重新登入進入後台；服務員看不到「註冊審核」。
- [ ] 退回一筆申請並寫原因 → 申請人看到「未通過」與原因。
- [ ] 舊方式：「我有團長給的代碼」用綁定碼註冊仍可用。

## 註冊與同意（階段 3 起可測）
- [ ] 綁定碼＋正確姓名 → 帳號 → 個資說明 → 同意 → 進到首頁
- [ ] 姓名打錯、代碼打錯：顯示同一句錯誤訊息
- [ ] 在個資說明頁按「不同意」：試算表「帳號」「綁定紀錄」都沒有新增
- [ ] 綁定碼用完次數後無法再註冊
- [ ] 帳號名稱重複（大小寫不同也算）被擋
- [ ] 告知內容改版（試算表新增第 2 版）後，家長重新開啟要求重新同意
- [ ] 家長自行解除綁定，孩子資料仍在

## 登入（階段 3 起可測）

- [ ] 連續錯 5 次被鎖定，60 分鐘後可再登入
- [ ] 登入過期：操作時跳回登入頁並提示，登入後回到原畫面
- [ ] 修改密碼後，其他裝置需重新登入
- [ ] 臨時碼重設密碼（階段 4A 起，後台產生臨時碼）

## 查詢端（階段 3 起可測）
- [ ] 入團日與在團時間正確
- [ ] 首頁順序：基本資料 → 下一步挑戰 → 正在挑戰的 → 已經拿到的 → 還沒開始的（預設收合）

- [ ] 說明留空的章不顯示空白區塊
- [ ] 技能章依服務類／健身類／技巧類分組

- [ ] 列印簽核單：用電腦列印成 A4，項目、完成日期、簽核人正確，未完成留空

- [ ] iPhone Safari、Android Chrome、LINE 內建瀏覽器都能正常使用

## 權限（4A）
- [ ] 家長帳號看不到「後台」按鈕；直接呼叫後台 API 也被擋（自動測試已涵蓋）
- [ ] 服務員：可點名、簽核、看名單與總覽、列印；看不到綁定碼、頒章、管理員、帳號、個資、備份、行事曆

## 管理員（4A）
- [ ] 從已註冊帳號指定服務員；對方重新整理後立即有後台
- [ ] 邀請碼流程：網頁產生 → 複製說明文字 → 對方註冊成服務員；試算表選單產生也可以
- [ ] 邀請碼過期、作廢後不能用
- [ ] 角色變更後權限立即改變
- [ ] 最後一位團長不可降級或移除；團長不可移除自己
- [ ] 被移除管理員後，仍可用家長身分看自己的孩子
- [ ] 管理員與家長畫面切換
- [ ] 連結 LINE 通知：輸入配對碼後收到「已連結」回覆

## 小狼與綁定碼（4A）
- [ ] 小隊設定：新增、改名（小狼一起更新）、上下調整順序、還有小狼的小隊不能刪
- [ ] 新增／編輯小狼時小隊只能用選的；點名與簽核的小隊按鈕依設定順序
- [ ] 新增小狼（入團日填過去日期）→ 自動產生綁定碼
- [ ] 複製給家長的說明文字，貼到 LINE 內容正確
- [ ] 重新產生綁定碼後舊碼失效
- [ ] 標記離團後綁定碼失效、名單篩選正確
- [ ] 查看誰綁了這位小狼、解除某個綁定

## 點名（4A）
- [ ] 行事曆一次貼上多筆、修改、取消（取消後不列入出席統計）
- [ ] 點名畫面預設今天的集會；依小隊篩選；點一下切換出席／請假／空白
- [ ] 「全部出席」只把空白的改成出席，請假的不變
- [ ] 點名未儲存就切換分頁或集會，會跳出提醒
- [ ] 兩位服務員同時點不同小隊，儲存後互不覆蓋
- [ ] 家長端集點卡與出席率正確；額外出席加上去最多 100%
- [ ] 羚羊「參加團集會至少 4 次」在第 4 次出席後自動打勾
