# 手動測試清單（TESTING）

> 範圍見 SPEC.md 第十一節；階段 4A 補到足以上線，階段 6 定稿。
> 測試一律使用虛構姓名（例如「測試小狼甲」），不得使用真實名單。
> 自動測試：`npm test`（純邏輯＋模擬試算表後端）、`npm run test:web`（模擬手機瀏覽器跑家長端流程）。
> 以下是**必須在真實手機、真實 Google 試算表**上做的檢查，打勾表示已實測。

## 註冊與同意（階段 3 起可測）
- [ ] 綁定碼＋正確姓名 → 帳號 → 個資說明 → 同意 → 進到首頁
- [ ] 姓名打錯、代碼打錯：顯示同一句錯誤訊息
- [ ] 在個資說明頁按「不同意」：試算表「帳號」「綁定紀錄」都沒有新增
- [ ] 綁定碼用完次數後無法再註冊
- [ ] 帳號名稱重複（大小寫不同也算）被擋
- [ ] 告知內容改版（試算表新增第 2 版）後，家長重新開啟要求重新同意
- [ ] 家長自行解除綁定，孩子資料仍在

## 登入（階段 3 起可測）
- [ ] 勾「記住我」：關掉瀏覽器再開仍在登入狀態
- [ ] 不勾「記住我」：關掉瀏覽器再開要重新登入
- [ ] 密碼錯、帳號不存在：顯示同一句「帳號或密碼錯誤」
- [ ] 連續錯 5 次被鎖定，60 分鐘後可再登入
- [ ] 登入過期：操作時跳回登入頁並提示，登入後回到原畫面
- [ ] 修改密碼後，其他裝置需重新登入
- [ ] 臨時碼重設密碼（階段 4A 起，後台產生臨時碼）

## 查詢端（階段 3 起可測）
- [ ] 入團日與在團時間正確
- [ ] 首頁順序：基本資料 → 下一步挑戰 → 正在挑戰的 → 已經拿到的 → 還沒開始的（預設收合）
- [ ] 已完成待頒發顯示「項目已全部完成，等待團長評核頒發」，不出現「可晉級」
- [ ] 說明留空的章不顯示空白區塊
- [ ] 技能章依服務類／健身類／技巧類分組
- [ ] 出席頁：出席、請假分開；沒點名顯示「－」；出席率最多 100%
- [ ] 列印簽核單：用電腦列印成 A4，項目、完成日期、簽核人正確，未完成留空
- [ ] 綁定兩個孩子時，上方可切換
- [ ] iPhone Safari、Android Chrome、LINE 內建瀏覽器都能正常使用
