# 第二期規劃（ROADMAP）

> 以下功能**現在不實作**，等團長明確說要做才開始。

## 家長回報
進程中有不少項目只有家長在家裡看得到（自行沐浴、訂定生活守則、打掃家庭等），第二期要讓家長能回報、由管理員確認。

- 家長在查詢端對未完成的項目按「回報完成」，可附一句說明。
- 寫入完成紀錄但回報狀態為「待確認」，回報人記該 LINE 帳號；待確認的項目不計入完成度與達標判定，查詢端顯示「已回報，等待確認」。
- 後台有「待確認回報」清單，管理員可逐筆或整批確認、退回（可附原因）。確認後才算完成，簽核人記確認的管理員。
- 哪些項目開放家長回報，由團長在項目管理中逐項設定。

## 第一期已預先做好的部分
- 「完成紀錄」已有「回報人」「回報狀態」兩欄（第一期一律留空）。
- 所有判定邏輯只把「回報狀態為空或已確認」的紀錄視為完成，第二期不必改資料結構。
