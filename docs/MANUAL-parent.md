# 22團網站　家長版操作手冊

> 網址：**https://aihong-lab.github.io/22CUBSCOUT/**（建議「加入主畫面」變成手機上的 App，方法見下方）
> 有任何問題請聯絡團長。完整版手冊：`docs/MANUAL.md`

## 把網站變成手機上的 App（加入主畫面）
不用到 App Store 下載，網站本身就可以裝到手機桌面，點開是全螢幕、沒有網址列：
- **iPhone**：用 **Safari** 打開網站 → 下方「分享」按鈕 →「加入主畫面」→「新增」。
- **Android**：用 **Chrome** 打開網站 → 右上角「⋮」→「安裝應用程式」（或「加到主畫面」）。
- 從 LINE 點開的網頁不能直接安裝：先按右上角「⋯」→「用預設瀏覽器開啟」，再照上面做。
- iPhone 第一次從桌面圖示打開時要**再登入一次**（桌面 App 和 Safari 的登入是分開的），之後就會記住。
- 網站更新時桌面 App 會自動跟著更新，不用重新安裝。沒有網路時 App 打得開，但資料要有網路才看得到。

## LINE 官方帳號（22團）
加入 22 團的 LINE 官方帳號後，聊天室下方有六個按鈕，點一下就打開網站對應的頁面：

| 位置 | 按鈕 | 打開什麼 | 要登入嗎 |
|---|---|---|---|
| 上排左 | 📣 公佈欄 | 最新公告、團集會通知 | 不用 |
| 上排中 | 🗺️ 進程查詢 | 剛入團、羚羊、狼、鹿、豹每一級要做什麼 | 不用 |
| 上排右 | 🎖️ 章查詢 | 各分團的章（幼童軍：26 個技能章的合格標準） | 不用 |
| 下排左 | 🧭 認識 22 團 | 團的介紹、五個分團、怎麼加入、聯絡方式 | 不用 |
| 下排中 | 📅 活動時間 | 團集會月曆、活動報名的起訖日 | 不用 |
| 下排右 | 👍 22團 FB | 22 團的 Facebook 粉絲專頁 | 不用 |

- 選單沒出現：點聊天室下方的「選單」兩個字就會展開。
- 在聊天室輸入「**進度**」，會回覆網站連結；登入後就能看孩子的進度。
- **官方帳號不會主動傳訊息給家長**，也不會收集你的 LINE 資料；孩子的進度、請假、活動報名都在網站上操作。
- 從 LINE 打開的網頁如果要登入、請假或報名，可以直接在 LINE 裡操作；想裝成手機 App 的話請照下一節，用 Safari 或 Chrome 開啟。

## 使用方式

### 1. 第一次使用：註冊（約 2 分鐘）
需要準備：**孩子的全名**。

1. 打開網站 → 右上角「🔑 登入」→「**註冊新帳號**」。
2. 選身分「**家長**」。（同時是家長和服務員的話選「服務員」，或先選家長，之後請團長幫你調整。）
3. 填**孩子的姓名**，並在旁邊**選孩子的分團**（稚齡童軍／幼童軍／童軍／行義童軍／羅浮童軍；不清楚就選「不確定」，團長會幫你設定）。有兩個以上孩子在團裡，按「＋ 再加一位孩子」，不同分團的孩子一次申請就好。再填你的**稱呼**（例如「王小明媽媽」）、**帳號**（4～20 個英文字母、數字或底線，例如 `xiaoming_mom`）、**密碼**（至少 8 個字；`12345678`、`password1` 這類太常見或跟帳號一樣的密碼會被擋）。
4. 閱讀**個資說明** → 勾選同意 →「同意並送出申請」。
5. 畫面會顯示「**等待團長審核**」。團長核准後，再登入（或按「重新整理」）就能看到孩子的冒險紀錄。

> 爸爸、媽媽可以各自註冊同一個孩子，團長審核時會把你們連到同一位小狼。
> 按「不同意」不會建立帳號，也不會留下任何資料。
> 如果團長給了你「綁定碼」，也可以用登入頁的「我有綁定碼」註冊，不需要等審核。

### 2. 之後登入
帳號＋密碼 → 勾「記住我」，這台手機下次就不用再登入。

### 3. 看孩子的進度（3 個分頁；手機在螢幕下方、電腦在上方）
| 分頁 | 看什麼 |
|---|---|
| 🏠 **首頁** | 孩子的基本資料、這一級的進度、技能章數、出席率；**下一步挑戰**（接下來要完成的任務）；下次集會；正在挑戰的、已經拿到的章 |
| 🗺️ **進度** | 上方可以切換三種：**闖關**（剛入團→羚羊→狼→鹿→豹，點關卡看每一項任務、完成日期、晉級條件、📋 本團細項，可列印簽核單）、**徽章**（技能章收藏冊，點徽章看合格標準）、**出席**（出席率、每次集會的紀錄） |
| 👤 **我的** | 帳號、修改稱呼與密碼、綁定的孩子、新增孩子、解除綁定、個資說明、登出 |

**體驗者**：還沒入團的孩子，首頁會顯示「一般團集會 x／4 次」。參加滿 4 次一般團集會（大活動不算）後，由團長轉為入團，之後開始挑戰「🌱 剛入團」。

**狀態說明**
- 🔒 未開始／🔥 挑戰中：還有任務沒完成。
- ⏳ 等待頒發：任務都完成了，「項目已全部完成，等待團長評核頒發」。
- 🏅 已拿到：團長已頒發，會顯示頒發日期。

> 孩子完成任務後，要在團集會時請團長或服務員**簽核**，網站上的星星才會亮起來。
> 進程是依團集會實際完成的內容簽核，所以孩子有時會先完成比目前級別更高的任務（例如羚羊級先做了豹級的木工），那一級會先顯示「🔥 挑戰中」，這是正常的。
> 家長在紙本簽名的項目，由團長登記到系統後才會亮起來。

### 3-0. 闖關只顯示兩關
「🗺️ 進度 → 闖關」只會顯示孩子目前這一級和下一級，例如目前是羚羊級，就顯示羚羊和狼。想看全部五級的內容，可以到網站上方的「進程查詢」（登出時會顯示全部）。

### 3-1. 公告、接下來的集會與請假
- 導覽列上有「📣 公佈欄」分頁（手機在螢幕下方），不用登入也看得到。
- **公佈欄**：團裡的公告會出現在網站首頁（不用登入也看得到）和你登入後的首頁。
- **接下來的集會**：「🗺️ 進度 → 🐾 出席」會列出接下來的集會（日期、名稱、備註）。
- **線上請假**：不能來的那一場按「請假」，點名時服務員就會看到；計畫改變可以按「取消」。已經過了的集會、或已經點名為出席（或遲到）的，請直接聯絡團長或服務員。請假不算出席。**請用這裡請假，不用再填 Google 請假表單**；也不用寫請假原因。
- 出席紀錄的符號：🐾 出席、⏰ 遲到（也算出席）、🌙 請假。
- 首頁也會顯示孩子的小隊輔是誰，以及孩子是不是小隊長、副小隊長。

- 網站首頁有**月曆**可以看每個月的團集會；LINE 官方帳號下方的按鈕也可以直接打開公佈欄、活動時間等頁面，這些都不用登入。

### 3-2. 活動報名
網站首頁「🎪 活動報名」（或 LINE 選單 → 活動時間的月曆）可以看到開放報名的活動。按「我要報名」→ 登入 → 每位填**姓名、身分別**和團長設定的題目；一次可以幫全家報名（按「＋ 再加一位」）。報名期間內、還沒繳費的可以自己取消。活動報名只開放 22 團的家長（要先通過團長審核）；活動結束後，網站上的報名資料會自動清除。繳費狀況由團長登記，你可以在同一頁看到「已繳／尚未繳費」。

### 4. 有第二個孩子與分團內容隔離
- 「👤 我的」→「＋ 新增孩子」→ 填孩子姓名並選分團 → 勾選同意 →「送出申請」。團長核准後，畫面上方可以切換孩子；切換時標題會顯示孩子的分團。
- **分團內容隔離**：登入後，系統只會顯示你所屬孩子分團（與全團開放）的公告、月曆與活動，不會看到其他分團的內部資料。實際顯示的分頁與功能（例如公佈欄、進度、請假、活動報名）均依總團「權限設定」為準。

### 4-1. 童軍以上（有手機）建立「本人帳號」
如果你的孩子是**童軍、行義童軍或羅浮童軍**且有自己的手機，可以由家長直接為孩子建立獨立的「本人帳號」：
1. 家長登入後到「👤 我的」→ 展開「**📱 為童軍以上孩子建立本人帳號**」。
2. 選擇要建立的孩子，設定孩子的登入帳號與初始密碼（至少 8 碼）→ 按「建立本人帳號」。
3. 孩子用自己的手機登入後，上方會顯示「🎒 本人帳號」標記，**僅能看到自己的進度與出席紀錄**，無法查看其他團員或他分團資料，也不能自行新增綁定或解除綁定。
4. 線上請假與活動報名預設由「家長」操作（是否開放給「童軍本人」由總團統一設定）。

### 5. 忘記密碼或帳號
請**聯絡團長**。團長會用 LINE 傳一組「**臨時碼**」給你：
登入頁 →「忘記密碼？」→ 輸入帳號、臨時碼、新密碼。臨時碼只能用一次，有使用期限。

### 6. 個資說明更新時
團長更新個資說明後，下次登入會請你重新閱讀並同意。

### 7. 不想再查看、或要刪除資料
- 不想再查看：「👤 我的」→「解除綁定」（孩子的紀錄不受影響）。
- 要刪除帳號或孩子的全部資料、或資料有錯要更正：請聯絡團長。

## 常見問題

**Q：送出申請很久了，還是顯示「等待團長審核」？**
A：團長還沒審核，請直接聯絡團長。如果顯示「未通過」，下面會有團長的備註。

**Q：輸入綁定碼一直顯示錯誤？**
A：請確認孩子的姓名和團裡登記的一模一樣（注意同音字），綁定碼的英文數字沒有打錯。還是不行的話，綁定碼可能已經用完次數或被重新產生過，請聯絡團長拿新的。錯太多次會暫時鎖住，請稍後再試。

**Q：網頁看起來是舊的？**
A：按 `Ctrl + Shift + R`（電腦）或關掉分頁重新打開（手機）。

**Q：畫面顯示「登入已過期」？**
A：重新登入即可，登入後會回到剛才的畫面。

**Q：家長或童軍本人帳號看得到別的孩子或其他分團嗎？**
A：不行。家長只看得到自己綁定的孩子與所屬分團的開放內容；「童軍本人帳號」更嚴格限制僅能查看自己的單一帳號資料。公開的進程與技能章查詢頁則不含任何孩子的個人資料。
