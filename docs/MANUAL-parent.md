- 🎖️ 技能章查詢：https://aihong-lab.github.io/22CUBSCOUT/web/#badges （26 個技能章的合格標準）

## 使用方式

### 1. 第一次使用：註冊（約 2 分鐘）
需要準備：團長用 LINE 傳給你的**綁定碼**（6 碼英文數字），以及**孩子的姓名**。

1. 打開網站 → 首頁按「🔑 登入」→「**我有代碼，要註冊**」。
2. 輸入**綁定碼**和**孩子的姓名**（要和團裡登記的一模一樣）→ 下一步。
3. 設定**帳號**（4～20 個英文字母、數字或底線，例如 `xiaoming_mom`）、**密碼**（至少 8 個字）、**稱呼**（例如「王小明媽媽」）。
4. 閱讀**個資說明** → 勾選同意 →「同意並完成註冊」。

> 爸爸、媽媽可以用同一組綁定碼各自註冊（每組綁定碼可用的次數由團長設定）。
> 按「不同意」不會建立帳號，也不會留下任何資料。

### 2. 之後登入
帳號＋密碼 → 勾「記住我」，這台手機下次就不用再登入。

### 3. 看孩子的進度（下方 5 個分頁）
| 分頁 | 看什麼 |
|---|---|
| 🏕️ **冒險** | 孩子的基本資料、在團時間、目前級別、收集的星星；**下一步挑戰**（接下來要完成的任務）；正在挑戰的、已經拿到的章 |
| 🗺️ **闖關** | 羚羊→狼→鹿→豹闖關地圖。點關卡看每一項任務是否完成、完成日期、晉級條件；可**列印這一級的簽核單**（A4） |
| 🎖️ **徽章** | 26 個技能章收藏冊。金色＝已拿到、有進度圈＝挑戰中、灰色＝還沒開始；點徽章看合格標準 |
| 🐾 **集點** | 出席率、出席與請假次數、每次集會的紀錄（🐾 出席、🌙 請假）、下次集會 |
| 👤 **我的** | 帳號、修改稱呼與密碼、綁定的孩子、新增第二個孩子、解除綁定、個資說明 |

**狀態說明**
- 🔒 未開始／🔥 挑戰中：還有任務沒完成。
- ⏳ 等待頒發：任務都完成了，「項目已全部完成，等待團長評核頒發」。
- 🏅 已拿到：團長已頒發，會顯示頒發日期。

> 孩子完成任務後，要在團集會時請團長或服務員**簽核**，網站上的星星才會亮起來。

### 4. 有第二個孩子
「👤 我的」→「＋ 新增綁定」→ 輸入第二個孩子的綁定碼與姓名 → 勾選同意 → 新增綁定。之後畫面上方可以切換孩子。

### 5. 忘記密碼或帳號
請**聯絡團長**。團長會用 LINE 傳一組「**臨時碼**」給你：
登入頁 →「忘記密碼？」→ 輸入帳號、臨時碼、新密碼。臨時碼只能用一次，有使用期限。

### 6. 個資說明更新時
團長更新個資說明後，下次登入會請你重新閱讀並同意。

### 7. 不想再查看、或要刪除資料
- 不想再查看：「👤 我的」→「解除綁定」（孩子的紀錄不受影響）。
- 要刪除帳號或孩子的全部資料、或資料有錯要更正：請聯絡團長。

## 常見問題

**Q：輸入綁定碼一直顯示錯誤？**
A：請確認孩子的姓名和團裡登記的一模一樣（注意同音字），綁定碼的英文數字沒有打錯。還是不行的話，綁定碼可能已經用完次數或被重新產生過，請聯絡團長拿新的。錯太多次會暫時鎖住，請稍後再試。

**Q：網頁看起來是舊的？**
A：按 `Ctrl + Shift + R`（電腦）或關掉分頁重新打開（手機）。

**Q：畫面顯示「登入已過期」？**
A：重新登入即可，登入後會回到剛才的畫面。

**Q：家長看得到別的孩子嗎？**
A：不行。家長只看得到自己綁定的孩子；公開的進程與技能章查詢頁不含任何孩子的資料。
