# 交接手冊（給下一任團長）

> 這份文件給「接手管理這套系統的人」。照著做，不需要會寫程式。
> ⚠️ 這份文件放在公開的 GitHub 上，**不要在這裡寫任何密碼、金鑰或孩子的姓名**。密碼請當面或用私人管道交接。

## 一、這套系統是什麼
- **網站**（家長、服務員、團長都用同一個）：https://aihong-lab.github.io/22CUBSCOUT/web/
- **資料**：全部存在一份 Google 試算表「幼童軍進程系統」，每週自動備份到同一個 Google 帳號的雲端硬碟。
- **程式**：放在 GitHub（網頁）與那份試算表的 Apps Script（後端）。
- **LINE 官方帳號**：只用來通知團長與服務員「有小狼達標了」，不會傳訊息給家長。
- 平常的操作全部在網站後台完成，說明見 `docs/MANUAL.md`。

## 二、要交接的東西（清單）
| 項目 | 是什麼 | 怎麼交接 |
|---|---|---|
| 團務 Google 帳號 | 擁有試算表、Apps Script、備份資料夾 | **最重要。**建議用團的共用帳號而不是個人帳號；交接時改密碼、改復原用的手機與信箱。如果原本用個人帳號，見第四節 |
| 網站的團長帳號 | 登入後台用 | 新團長自己在網站註冊（身分選「服務員」）→ 舊團長**用 admin 登入**，在「管理員」把對方改成團長 → 新團長確認能登入後，再把舊團長降為服務員或移除 |
| `admin` 預設帳號 | **最高權限帳號**：只有它能指定或取消團長，別人動不了它 | 新團長在試算表選單「🐺 幼童軍系統 → 🔑 團長預設帳號（admin）」重設密碼（新密碼只會顯示一次） |
| GitHub 帳號／repo | 網頁程式 `AIhong-lab/22CUBSCOUT` | 把新團長加為 repo 的管理者（Settings → Collaborators），或移轉整個 organization 的擁有者 |
| LINE 官方帳號 | 通知用 | LINE Official Account Manager →「設定 → 權限管理」新增新團長為管理員；LINE Developers Console 的 Provider 也要加 |
| 個資告知同意內容 | 試算表「告知同意內容」 | 裡面的聯絡人如果是舊團長，新增一版改成新團長（家長下次登入會重新同意） |

## 三、交接當天照順序做
1. 新團長在網站註冊帳號，舊團長核准並設為**團長**。
2. 新團長登入後台，確認看得到「管理員」「系統設定」「備份與權限」。
3. 新團長到「更多 → 連結 LINE 通知」連結自己的 LINE；舊團長到同一頁按「解除連結」。
4. 交接團務 Google 帳號（或照第四節移轉擁有權），新團長確認打得開試算表與「擴充功能 → Apps Script」。
5. 後台「備份與權限」→ 按「立即備份」「檢查試算表權限」，都要成功。
6. 重設 `admin` 預設帳號密碼。
7. 舊團長的網站帳號改成服務員或移除；GitHub、LINE 的權限也移除。
8. 檢查「管理員」清單，移除已經不在團裡的服務員。

## 四、如果試算表在舊團長的個人 Google 帳號
後端程式、每週備份與每日通知的排程，都是用「擁有者的身分」執行的，所以不能只把試算表共用給新團長：
1. 舊團長把試算表的**擁有權**轉給新團長（共用 → 把對方設為擁有者；對方要接受）。
2. 新團長打開「擴充功能 → Apps Script」→ 執行一次 `setup`（會用新團長的身分重新建立備份資料夾與排程，不會動到既有資料）。
3. 新團長「部署 → 管理部署作業 → 鉛筆 → 版本選新版本 → 執行身分選『我』→ 部署」。如果網址變了，要請維護人員把新網址更新到網頁的 `GAS_URL` 與 LINE 的 webhook。
4. 舊團長到自己的 Apps Script「觸發條件」刪掉舊的排程。
⚠️ 這個移轉流程沒有實際演練過，做之前先按一次「立即備份」，並找維護人員一起做。

## 五、每年固定要做的事
| 時機 | 要做的事 |
|---|---|
| 學年開始 | 行事曆加入新學年的集會；「年度出席」新增新年度；確認小隊清單、小隊輔、正副小隊長 |
| 新生入團 | 新增小狼或體驗者（人多用批次匯入）；請家長自己註冊，團長在「帳號申請」核准 |
| 每次團集會 | 點名 → 簽核 → 頒章（後台首頁會提醒誰達標了） |
| 學年結束 | 升上童軍團的小狼標記「升團」 |
| 離團／升團後 | 依告知同意內容寫的保存期限，在「個資處理」把資料匿名化（後台首頁會提醒） |
| 每年至少一次 | 請維護人員比對童軍總會是否更新進程、技能章內容 |
| 隨時 | 後台首頁出現紅色或黃色提示時照指示處理 |

## 六、出問題的時候
- **網站打不開或顯示錯誤**：先看 `docs/MANUAL.md` 的常見問題。
- **資料改錯了**：試算表「操作日誌」分頁記了每次修改前後的值；雲端硬碟「幼童軍進程系統備份」資料夾有每週備份（保留最近幾份）。
- **忘記團長密碼**：打開試算表 → 選單「🐺 幼童軍系統 → 🔑 團長預設帳號（admin）」重設。
- **要改功能或修問題**：這個專案由 AI 助理（Claude）維護，開新的對話時請它先讀 repo 裡的 `CLAUDE.md` 與 `docs/SPEC.md`。所有決定的來龍去脈都記在 `docs/SPEC.md` 的附錄與 `docs/CHANGELOG.md`。

## 七、不可以做的事
- 不要刪除或調換試算表的欄位、分頁（要加欄位只能加在最右邊，而且要請維護人員改程式）。
- 不要把試算表設成「知道連結的任何人都能看」。
- 不要把密碼、LINE 的 token、孩子的名單貼到 GitHub 或任何公開的地方。
- 不要在系統裡記錄孩子的生日、身分證字號、電話、地址、照片。
- 公佈欄是公開的，不要寫孩子的姓名。
